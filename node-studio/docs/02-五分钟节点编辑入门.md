# 五分钟节点编辑入门

## 认识页面

页面分为四块：左侧是节点库，中间是节点画布，右侧是配置检查器，底部是运行结果和轨迹。

## 跑通第一张图

1. 在顶部“示例图”选择“基础聊天”。
2. 点击“检查图”，看到“图有效”后继续。
3. 点击“运行”。
4. 底部会显示预览结果；`sent` 永远是 `false`，表示没有真正发送。
5. 点击执行轨迹中的节点，可查看它收到和产生的数据。

## 修改消息

1. 点击画布上的“消息输入”节点。
2. 在右侧找到消息配置，修改 `text`。
3. 点击“检查图”，再点击“运行”。

轨迹会对消息正文、身份及上下文做脱敏，不会原样展示敏感内容。

## 添加节点和连线

1. 点击左侧节点库中的节点，节点会添加到画布。
2. 点击上游节点的输出端口。
3. 兼容的输入端口会被标记，点击目标输入端口完成连线。
4. 单值输入重新连线时，原连线会被替换；多值输入允许多条兼容连线。
5. 点击“检查图”确认端口类型、必需输入、环和安全出口都正确。

## 删除节点

选中节点后，点击右侧“删除节点”，或在没有编辑输入框时按 Delete/Backspace。删除节点会同时删除它的连线。

## 必须知道的安全出口

所有可预览回复必须依次经过：

```text
出口审核 → 人味处理 → 预览输出
```

绕过其中任何一步，图校验都会失败。这一约束不能通过节点配置关闭。

## 退出前

v0.1.0 不保存画布修改。需要保留思路时，请在退出前截图或手工记录配置；不要把真实账号、Token、服务器地址或生产消息填入演示图。
