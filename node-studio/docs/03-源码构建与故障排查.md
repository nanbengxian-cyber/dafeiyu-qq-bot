# 源码构建与故障排查

## 环境

运行源码只需要 Python 3.8 或更高版本，不需要安装第三方运行依赖。构建 Windows EXE 需要 Windows 10/11 和联网安装构建依赖。

## 从源码运行

PowerShell：

```powershell
python -m dafeiyu_flow.desktop
```

Linux：

```bash
bash scripts/start-studio.sh
```

只启动服务、不打开浏览器：

```powershell
python -m dafeiyu_flow.desktop --no-browser --port 0
```

## 运行检查

```powershell
python -m compileall -q dafeiyu_flow tests packaging scripts
python -m unittest discover -s tests -v
```

所有测试通过后才应打包。

## 构建 Windows EXE

在项目根目录打开 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\packaging\build-windows.ps1
```

脚本会重新创建 `.build-venv`，安装固定版本的 PyInstaller，运行检查并输出：

```text
dist\dafeiyu-node-studio.exe
dist\dafeiyu-node-studio.exe.sha256
```

Python 不在 PATH 时可指定完整路径：

```powershell
.\packaging\build-windows.ps1 -PythonExecutable "C:\Program Files\Python38\python.exe"
```

## 生成源码归档

```powershell
python .\scripts\make-release.py
```

归档器只接受显式白名单中的文件，会拒绝缺失文件或检测到的生产标识、私钥、Token 和私网地址。输出 ZIP 内含 `SOURCE-MANIFEST.json`。

## 常见构建问题

- **ExecutionPolicy 阻止脚本**：只为当前 PowerShell 执行 `Set-ExecutionPolicy -Scope Process Bypass`。
- **测试失败**：不要跳过并发布；先修复失败，再重新构建。
- **EXE 被安全软件拦截**：从仓库 Release 下载并核对 SHA-256；未签名的 PyInstaller 程序可能触发信誉提示。
- **端口冲突**：使用 `--port 0`，或直接让默认启动自动回退。
- **路径含中文/空格**：构建脚本以参数数组调用 Python；仍建议在 Windows 标准用户环境再跑一次完整检查。

## 安全边界

不要把生产机器人配置、聊天记录、IP、域名、账号或 Token 加入示例、测试、日志和源码包。本项目当前不应部署到生产机器人目录。
