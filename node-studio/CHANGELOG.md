# 更新记录

## v0.1.0（2026-09-11）

首个可下载的离线原型版本。

### 新增
- 类似 Blender 几何节点的浏览器可视化编排界面。
- 固定 12 类类型化节点和 3 张脱敏离线示例图。
- 图结构检查、DAG 拓扑执行、运行轨迹和录制重放。
- Windows 单文件 EXE 打包链与 GitHub Actions 自动构建。
- 源码白名单归档、文件清单和 SHA-256 校验文件。

### 安全
- Studio 仅监听 `127.0.0.1`，不连接 QQ、AstrBot、服务器或生产环境。
- 变更请求启用 Host、Origin、CSRF、Cookie 和请求体限制。
- 强制执行出口审核 → 人味处理 → 预览输出安全链。
- 轨迹中的消息、上下文与身份文本仅保留长度和截断摘要。
- 会话、运行记录、慢连接及 HTTP 并发均有上限和过期清理。

### 修复
- 修复编辑器新建连线缺少唯一 ID、导致图无法运行的问题。
- 修复跨会话读取运行记录、宽松回放路由及畸形 Cookie 处理问题。
- 修复会话容量边界、运行记录无限增长和处理线程无上限问题。
- 修复快速切换示例图时旧响应覆盖新页面，以及旧运行结果标记新图的问题。
- 修复 Windows 构建脚本无法可靠处理含空格或中文路径的问题。

### 已知限制
- 画布修改只保存在当前页面内存中，刷新、切换示例或退出会丢失。
- 当前是假模型和预览输出，不会真正向 QQ 发送消息。
- 尚未提供 AstrBot 兼容层、持久化用户图、控制流分支和异步调度。
