# 大肥鱼机器人控制台（Windows EXE）

一个给新手用的 Windows 控制台：**填好服务器和仓库信息，点一下，服务器自己去仓库下载源码、自动部署并启动机器人**；部署完成后控制台还能显示和修改配置项。

不需要懂 Docker，也不需要登录服务器敲命令。

---

## 它到底做什么

| 步骤 | 控制台做的事 | 服务器上发生什么 |
|---|---|---|
| 1 | 你填写服务器地址、SSH 账号密码或私钥、仓库地址 | 无 |
| 2 | 点「测试连接」 | 只读检查系统、Git、Docker、磁盘、权限 |
| 3 | 点「开始部署」 | 必要时装 Git/Docker → 从仓库下载源码 → 生成容器编排 → 拉镜像 → 启动容器 |
| 4 | 自动读取配置清单 | 从部署目录读 `deploy/console-config.json` 和 `deploy/robot.env` |
| 5 | 你改配置、点「应用配置」 | 行级写回配置；需要生效的项自动重建容器 |

安全边界：

- 密码、私钥口令**只留在内存**，不写文件、不进日志。
- 只管理带专用标记文件的部署目录，**不会删除或覆盖别人的目录**。
- 日志全部脱敏（URL 里的凭据、`token=`/`password=` 一律打码）。
- 默认拒绝未知主机指纹；确认服务器可信后才勾选接受。
- 控制台**不会主动连接任何已有机器人**，除非你显式填入它的地址。

```text

├── app.py                  # 界面：连接与部署 / 配置与状态 / 新手教程

├── tests/                  # 离线测试，不需要真服务器
└── README.md
```

## 新手教程（六步）

### 第 1 步：准备服务器

- 一台 Linux 服务器（推荐 Debian 12 / Ubuntu 22.04），内存 2 GB 以上。
- 能用 SSH 登录（地址、端口、用户名、密码或私钥）。
- 安全组放行：SSH 端口、NapCat 端口（默认 3001）、AstrBot 端口（默认 6185）。

### 第 2 步：填写「连接与部署」

| 字段 | 怎么填 |
|---|---|
| 服务器地址 | 公网 IP 或域名，**不要带 `http://`** |
| SSH 端口 | 一般是 22 |
| SSH 用户名 | 一般是 root |
| 登录方式 | 密码或 SSH 私钥（私钥只在你电脑上使用） |
| 首次连接接受服务器指纹 | 第一次连这台机器时勾选 |
| 源码仓库地址 | `https://<你的代码托管域名>/<账号>/<仓库>.git` |
| 分支或标签 | 一般填 `main` |
| 服务器部署目录 | 默认 `~/dafeiyu-bot` |

> 私有仓库：先在服务器上配置部署密钥，再填 `git@<主机>:<账号>/<仓库>.git`。

### 第 3 步：测试连接

点「测试连接」，看到「连接成功」和系统/权限/磁盘信息即可。这一步**不改服务器**。

### 第 4 步：开始部署

点「开始部署」并确认。日志区会实时显示：下载源码 → 准备目录 → 拉镜像 → 启动服务。

### 第 5 步：改配置

切到「配置与状态」：

- 顶部显示两个容器是否在运行、端口映射是否正常。
- 下面的配置项由仓库里的 `deploy/console-config.json` 决定，**部署后自动出现**。
- 改完点「应用配置」。标着「改完需要重启服务」的项会自动重建容器。
- 敏感项（如搜索接口密钥）只显示「已设置/未设置」，真实值永远不出服务器。

### 第 6 步：登录 QQ

1. 浏览器打开 `http://<服务器地址>:<NapCat端口>` 扫码登录机器人 QQ 号。
2. 再打开 `http://<服务器地址>:<AstrBot端口>` 完成模型和人格配置。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 首次连接该服务器 | 勾选「首次连接接受服务器指纹」，或先用系统 `ssh` 确认指纹 |
| SSH 登录失败 | 检查用户名、密码/私钥、端口；服务器可能只允许密钥登录 |
| 当前账号无权访问 Docker | 用 root，或把用户加入 `docker` 组 |
| 部署目录已存在且不是本控制台创建的 | 换一个部署目录；控制台不会删别人的目录 |
| 镜像拉取失败 | 检查服务器能否访问容器镜像仓库，必要时配代理 |
| 端口被占用 | 在「服务端口」里改端口后重新部署 |
| 没有配置项 | 仓库里缺少 `deploy/console-config.json`，或还没部署成功 |

## 在 Windows 打包 EXE

在 Windows 开发机上执行：

```powershell
cd desktop-controller
powershell -ExecutionPolicy Bypass -File .\build-windows.ps1
```

脚本会在本目录创建 `.venv-build` 虚拟环境（不污染系统 Python），成功后得到：

```text
dist\大肥鱼机器人控制台.exe
```

把这个 EXE 复制给使用者即可。EXE 里**不含**任何服务器地址、密码、私钥或机器人配置；
使用者第一次运行时自己填写，只有非敏感字段会保存在 EXE 同目录的
`controller-profile.json`（密码、私钥路径、口令不保存）。

## 本地测试

```bash
python3 -m unittest discover -s tests -v
```

测试用假传输层模拟 SSH 与服务器文件系统，**不会连接任何真实服务器**：

- 配置清单解析、取值校验、敏感项不回显、env 行级写回
- 部署脚本生成（shell 转义、标记目录保护、不含明文密码）
- 部署流程调用顺序、错误信息脱敏、容器状态解析
- 本地配置只保存非敏感字段

## 脱敏规则

提交代码、日志、截图和教程时一律使用占位符：

- 地址：`<服务器地址>` / `https://<你的代码托管域名>/<账号>/<仓库>.git`
- 账号：`<管理员账号>` / `<管理员 QQ 号>`
- 密钥：`<仅在服务器本地设置>`
- 路径：`<服务器上的私有路径>`

不要提交真实 IP、域名、QQ 号、群号、Cookie、Token、API Key、私钥、证书或完整生产路径。
