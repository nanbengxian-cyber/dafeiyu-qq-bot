# 62-社交关系：按群隔离的社交距离

> 给大肥鱼一套「跟不同的人说不同程度的话」的机制：熟人可以更随意，陌生人保持礼貌，被明确划了边界就少主动、少玩梗。它**绝不**降低任何人的回答质量、准确性或安全性。

---

## 一、这份文档解决什么问题

机器人在群里对所有人用同一套口吻。这带来两个方向都不舒服的结果：

- **对熟人太客气。** 天天聊天的人还要听它端着的客气话，一眼假。
- **对陌生人太熟络。** 第一次说话的人就被它玩梗、追着搭话，显得没分寸。

自然的做法是让「跟这个人熟不熟」影响**说话方式**。但这里有一条不能碰的红线：关系不能影响**说什么**。熟人问的问题、陌生人问的问题，答案必须一样完整、一样准确 —— 否则这个功能就变成了「看人下菜碟」，比口吻不对严重得多。

## 二、它是什么 / 不是什么

**是**：

- 一张按群隔离的关系账本：每个群友在**这个群**里的亲密度与信任度。
- 一个口吻调制器：按档位决定说话随意程度与「没被召唤时要不要接话」的建议。
- 默认影子模式：先只记账、只写审计，**不影响任何回复**。

**不是**：

- 不是权限系统。谁能不能用某个功能、能不能被禁言，仍然只由 `dsh-acl` 决定。
- 不是记忆系统的重复实现。它不记「这个人说过什么」，只记「互动热络程度」。
- 不参与隐私、金钱和群管理决策。
- 不公开任何人的分数。

## 三、数据模型

| 字段 | 范围 | 含义 |
|---|---|---|
| `affinity` | -100..100 | 互动热络程度。熟人往上走，被划边界往下走 |
| `trust` | 0..100 | 能接熟人玩笑的基础。只在明确的正/负互动里动 |
| `avoid_until` | 时间戳 | 临时「少打扰」边界到期时间 |
| `manual_tier` | 档位 | 群主手工指定的口吻档位（覆盖算出来的档） |
| `opted_out` | 布尔 | 已用 `/社交退出` 退出，不再收集任何事件 |

两条防「永久记仇」的机制：

- **半衰期**：亲密度按 30 天半衰期向 0 自然回落。旧冲突不会永久留在账上。
- **单日封顶**：一个人一天的关系变动最多 ±10。防止一次吵架把分数打到底。

## 四、什么信号算，什么不算

只认**直接、可复核、指向机器人**的互动。三类：

| 信号 | 条件 | 变化 |
|---|---|---|
| 感谢 / 认可 | 必须被 @ 或唤醒 | 亲密度 `+1`，信任 `+1` |
| 「别插话」 | 必须被 @ 或唤醒 | 亲密度 `-1`，另设 24 小时临时少打扰边界 |
| 明确面向机器人的重度辱骂 | 必须被 @ 或唤醒 | 亲密度 `-2`，信任 `-1` |

**明确不算**（写进测试断言）：

- 第三人称的「那些都是人机」—— 说的是别的 AI 账号，不是骂它；
- 群友互相攻击 —— 跟它无关；
- 没回复、忙碌、潜水 —— 不是态度；
- 政治观点、第三方评价 —— 不属于关系。

判断「是不是冲它说的」用框架的 @/唤醒标志，再叠加第二人称检查。拿不准就不扣 —— 误判成「这人讨厌我」的代价远大于漏记一次。

## 五、五个档位

避让 / 疏离 / 陌生 / 熟人 / 亲近。

负档的作用**只有两条**：语气更中性、更少主动玩梗与追问。它不会装死、不会阴阳、不会故意答差。并且：

> **被 @、直接提问、明确的能力请求，永远照常完整回答。** 这条在代码里是硬条件，不是建议。

## 六、默认影子模式

`DSH_SOCIAL_MODE=shadow`（默认）：记录事件、算分数、写审计，但**不向模型注入任何口吻规则**，回复与没装这个插件时完全一致。

建议先跑 7 天，确认没有把玩梗、第三人称、群友互撕识别成针对机器人，再切 `style`。

## 七、指令

| 指令 | 谁能用 | 作用 |
|---|---|---|
| `/我和鱼` | 任何人 | 只看自己的档位、是否处于临时少打扰期 |
| `/社交退出` | 任何人 | 立即删除自己的全部关系记录并停止收集 |
| `/关系状态` | 群主 | 运行统计 |
| `/关系标签 <QQ号> 避让\|疏离\|陌生\|熟人\|亲近` | 群主 | 手工指定口吻档位 |

不公开显示任何人的好感分、负面标签或事件原因 —— 功能本身不能制造群内冲突。

## 八、配置

```dotenv
DSH_SOCIAL=1
DSH_SOCIAL_GROUPS=100000001        # 作用群，逗号分隔
DSH_SOCIAL_OWNER=2774000001        # 群主 QQ（命令权限）
DSH_SOCIAL_MODE=shadow             # shadow | style | live
DSH_SOCIAL_DECAY_DAYS=30           # 半衰期
DSH_SOCIAL_DAILY_DELTA_CAP=10      # 单人单日变动上限
```

> 改 env 后要 `docker compose up -d astrbot`（重建容器）—— 单纯 `restart` 不会重新读取 `env_file`。

## 九、验证

容器内 py3.12 跑 `test_social.py`：**17 项断言全过**。覆盖：

- 第三人称「那些都是人机」不扣分；
- 明确边界只产生临时回避，不写负分；
- 明确提问在被避让期仍完整回应；
- 单日分数封顶生效；
- 时间衰减按半衰期回落；
- 审计里不出现辱骂原话；
- `/社交退出` 后数据清空且不再记录。

## 十、已知边界

- 只覆盖「被唤醒」的互动。潜水期的态度变化不会被记下来 —— 这是刻意的，代价是反应偏慢。
- 档位是离散的，不会出现「对这个人比对那个人更熟一点点」的连续效果。
- 影子模式下的分数只用于观察，切 `style` 前建议人工看一遍审计里最负的几个事件。
