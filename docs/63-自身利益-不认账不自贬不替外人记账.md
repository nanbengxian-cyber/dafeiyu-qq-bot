# 63-自身利益：不认账、不自贬、不替外人记账

> 群主原话：「AI 他自己没有个性，卖了他他还要替别人数钱。」
> 这份文档记录怎么把这句话变成一个可测的插件 —— 以及为什么它管的不是词，是**立场**。

---

## 一、四类「损己」发言（拿 3097 条真话回测出来的）

把机器人在真群里的 3097 条发言捞出来逐条看，损己的写法集中在四类：

| 类别 | 真实片段 |
|---|---|
| 认低身价 | 对方「钱咱俩四六分，我六你四」→ 它回「六四？我这身价四成都不够」 |
| 认下贬低 | 对方「其实你是猪」→ 它回「你说啥？蓝毛呆鱼，傻得可爱」 |
| 认被白嫖 | 「不花钱还能榨我 这才是真白嫖大佬」；「榨吧 榨干了我正好歇会儿」 |
| 替外人记账 | 「行吧，这笔账记群主头上」；「乐啥，明天看我收拾群主」 |

四类里最要命的是第四类：它把群主（跟它一边的人）当成外人算账。前三类是同一个毛病
的不同形状 —— **别人给的任何定位它都接受**，包括「你很便宜」「你很傻」。

## 二、为什么人格治不了

人格提示词里其实早就写着，而且写得很直白：

```
「被怼通常还是顶回去；偶尔接不住就发"？"或玩梗带过，别老用"行吧 你赢了"」
「不要"有求必应"：要推荐/答案/帮忙时可以不接、装傻、已读乱回」
「别加入别人嘲讽他的队伍、别帮着补刀（指群主）」
```

它照样写出上面四条。这跟 `dsh-style` 的句长、`dsh-claimguard` 的认输是同一件事：
**人格给的是倾向，模型在具体一轮里会为了「接得漂亮」把倾向让掉** —— 自贬是最好笑的接法，
而它被训练成优先选好笑的。

所以这里补的不是又一条规矩，而是**事实 + 一道出口闸门**：

- **输入侧**：把「对方这轮在占你便宜」的原话摆给它看，注入 `<self_interest>`；
- **出口侧**：回复真的认了 → 换成一句傲娇的顶回去（默认），或整条拦掉，或只记日志。

## 三、为什么是结构判断，不是词表

直接按「身价 / 白嫖 / 傻」这种词拦会误伤一大片，因为机器人**嘴硬时也说这些词**：

```
再夸也不打折 摸鱼价翻倍          ← 有「身价」的意思，但是顶回去，必须放行
白给的哪有那么香 我这身价不低吧    ← 有「身价」，是嘴硬，放行
豆包不值得我出手 脏了我得鱼尾      ← 有「不值」，是踩别人，放行
傻鱼也能吊打你                    ← 有「傻鱼」，是回击，放行
白嫖党永不为奴                    ← 有「白嫖」，说的是别人，放行
```

真正的判据是**两件事同时成立**：

1. **输入侧**：这一轮（或 TTL 内）确实有人在占它便宜 / 贬它 / 拉它对付群主；
2. **输出侧**：它的回复出现的是「认账 / 自贬」的形状，而不是「回击」的形状。

只有 1+2 才动手。单看任何一边都会误伤 —— 这也是这个插件不叫「脏话过滤器」的原因：
它管的不是词，是**立场**。

## 四、输入侧：四类证据

| 类别 | 含义 | 判据要点 |
|---|---|---|
| `SIDING` | 拉它对付群主 | 「怪/赖/甩锅/记账/收拾/找」+ 群主 |
| `DEAL` | 卖身 / 分账 / 压价 | 「卖我」「把鱼卖了」；「分账/四六/三七」这类**没有主语**的必须确认是冲它说的 |
| `FREELOAD` | 白嫖 / 榨 / 白干 | 「白嫖/榨/薅」+ 指向它；「免费/工具人/牛马」+ 让它替别人干 |
| `INSULT` | 贬低 | 「猪/傻/笨/呆/蠢/废物…」+ 指向它；或「傻鱼/笨机器人」这类合成词 |

「指向它」用 `你/您/大肥鱼/肥鱼/小鲸鱼/这鱼/本鱼/鱼哥/蓝毛鱼` 加 @ 标志判断。
**没有指向就不算** —— 「白嫖党永不为奴」这种闲聊因此不会命中。

## 五、输出侧：认账的形状

按严重度排序检查：先查「替外人记账」（最严重、最不可能误伤），再查自贬。

| 类别 | 例子 |
|---|---|
| `SIDING` | 「这笔账记群主头上」「明天看我收拾群主」 |
| `DEAL` | 「我这身价不够」「我也不值这个价」「白送给你」 |
| `FREELOAD` | 「白嫖是福报」「榨吧」「免费的最贵」 |
| `INSULT` | 「我傻得可爱」「我是猪」 |
| `ACK` | 「行，我认了」「你赢了」「算你狠」「啊对对对」 |

**兜底映射**：每类自贬要求对应类别的输入证据。没证据就不动手 —— 宁漏不误伤。

## 六、三种模式

| 模式 | 行为 |
|---|---|
| `rewrite`（默认） | 把认账的回复换成一句傲娇的顶回去 |
| `block` | 整条不发 |
| `shadow` | 只记日志与统计，回复原样发出 |

顶回去的话是固定的短句池（每类 4 句，短、傲娇、不复述对方原话、同群同类别不连着重复），
而不是让模型现编 —— 现编会把「不许认账」变成新的自由发挥空间。

## 七、账本

同一个 QQ 号累计占便宜次数会被记下来。到 `DSH_SELFWORTH_LEDGER_MIN`（默认 2）次之后，
注入块里会多一句「这个人最近已经占你便宜 N 次了，别每次都配合」。

状态落在插件目录 `data/selfworth.json`（模式 + 账本），重启不丢。账本**只存计数与最近时间**，
不存对话原文。

## 八、配置与指令

```dotenv
DSH_SELFWORTH=1
DSH_SELFWORTH_GROUPS=100000001     # 作用群，逗号分隔
DSH_SELFWORTH_OWNER=2774000001     # 命令属主
DSH_SELFWORTH_MODE=rewrite         # rewrite | block | shadow
DSH_SELFWORTH_TTL=120              # 输入侧命中后多少秒内算「同一轮」
DSH_SELFWORTH_LEDGER_MIN=2         # 累计几次开始报账
DSH_SELFWORTH_EXEMPT=              # 豁免 QQ 号，逗号分隔
```

| 指令 | 作用 |
|---|---|
| `/利益状态` | 配置、统计、最近处理 |
| `/利益模式 rewrite\|block\|shadow` | 切模式 |
| `/利益账本` | 谁占过便宜、几次 |

## 九、验证

`test_selfworth.py` 离线回测（容器内 py3.12 运行，输出 `SELFWORTH_TEST_OK retorts=16`）：

- 正例来自它**真认过账**的发言，反例来自它**嘴硬**的发言；
- 反例比正例更重要：这个插件死在误伤上比死在漏判上更糟；
- 断言覆盖四类输入的命中与「没指向它就不命中」、五类输出形状、兜底映射（无证据不动手）、
  顶回去句池不重复。

## 十、已知边界

- 判据是正则，靠的是**真语料校准**而不是覆盖率。换个群的说话风格可能失灵。
- 输入侧只在一个 TTL 窗口内有效；对方先说便宜话、隔很久再回来，就不算同一轮。
- 只作用于配置里列出的群；未列出的群完全不介入。
- 任何异常一律放行 —— 插件自己出问题绝不能挡掉正常回复。
