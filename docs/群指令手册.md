## 一、先看这个：指令怎么发才有效

**两种发法都行**，任选其一：

| 发法 | 例子 | 说明 |
|---|---|---|
| 斜杠开头 | `/画图状态` | 最常用。斜杠必须是消息第一个字符 |
| @机器人 再写指令名 | `@小鲸鱼 画图状态` | 不用加斜杠。@ 必须在最前面 |

**为什么**：框架的唤醒前缀配置成了 `/`；而 @ 机器人时第一个 @ 不会算进消息正文，
所以 `@机器人 画图状态` 的正文正好就是 `画图状态`，同样能匹配上。
**两种发法都受权限门卫管**，绕不过去。

**不生效的几种情况**：

- 斜杠前面有空格或别的字（`我发个 /画图` 不行）
- 先 @ 了别人再 @ 机器人（第一个 @ 不是机器人时不唤醒）
- 指令名写错一个字就完全不匹配，机器人会当普通聊天去问模型

**带参数的指令，指令名和参数之间要有空格**：`/画图 一只戴墨镜的橘猫` ✓，`/画图一只猫` ✗。

## 二、权限分三档

| 档位 | 谁能用 | 判定依据 |
|---|---|---|
| 🔴 群主 | 只有群主 | QQ 号在 `DSH_ACL_OWNER` 里，或群内身份是 owner |
| 🟡 管理员 | 群主 + 群管理 | 上面那条，或群内身份是 admin |
| 🟢 所有人 | 谁都能用 | 无限制 |

**分档只看一件事：这条指令的后果由谁承担。** 后果落在全群的归群主，
只是诊断信息的归管理员，后果只落在自己身上的谁都能用。

越权时机器人会说一句「这条只有群主能用」并给出替代建议，指令**不会执行**。
同一个人 30 秒内只提示一次（防刷屏），但仍然拦。

发 `/权限` 看自己这一档有哪些；群主和管理员可以发 `/权限状态` 看门卫的拦截统计。

## 四、详解

### 4.1 画图

```
/画图 一只戴墨镜的橘猫
```

不经过模型，直接调生图接口，所以「模型嘴上答应却不出图」这条路绕开了。
当前渠道是 Agnes，主模型 `agnes-image-2.5-flash`，两个备用模型会在主模型失败时自动降级，
出图尺寸 1024×1024，超时 120 秒。

画风默认加了二次元可爱简笔画的后缀，所以出来的图偏卡通。

**冷却 8 秒**，同一个群里连着发第二条会被挡住并告诉你还剩几秒。

**不用指令也能出图**：直接说「画个猫娘」「给我生成一张海报」「弄个懒羊羊」都会触发。
判定逻辑是「你要图 + 模型没明确拒绝 + 模型不是在反问画什么」，
所以句子里有没有「图」这个字都不影响。

### 4.2 语音

```
/说话 哼，才不是特意帮你呢
```

🔴 **换音色只有群主能用**（会话级全局状态，换了之后所有人听到的都变了）：

```
/音色                    ← 看当前音色
/音色 派蒙               ← 按名字搜索并临时切换
/音色 626bb6d3f336...    ← 直接填 32 位音色 ID
```

接 Fish Audio，当前模型 `s2.1-pro-free`（付费档余额为 0，所以用免费档），
两个备用模型会降级。

**限制**：单条最多念 120 字，超了按句末标点截断。**冷却 20 秒**。
`/音色` 切换只在本次运行期间有效，机器人重启后回到默认音色。

**不用指令也能发语音**：说「用语音说」「念一句给我听」「唱首歌」会触发。
但判定刻意收得很严 —— 语音是打扰性输出，宁可漏不可扰，所以「随便说句话」「讲两句」
这种不会误判成要语音。

### 4.3 视频

🔴 **只有群主能用**：

```
/做视频 一条鲸鱼在海里翻身
```

Agnes `agnes-video-v2.0`，出 5 秒 1280×720 的片子。

**这条最需要耐心**：生成一次实测约 4 分钟。指令会立刻回一句「在做了」然后后台跑，
做完单独发一条消息 —— 不这么做的话，整个会话会被锁 4 分钟，期间群里谁说话机器人都不理。
这也是它归群主的原因：一个人就能把全群堵住 4 分钟。

**冷却本群 5 分钟 + 全局 75 秒**（渠道方限流 1 请求/分钟），最长等 10 分钟不出就放弃。

**看视频是自动的**，不用指令：群友发的视频会抽 4 帧交给视觉模型认，再把描述喂给聊天模型。
最长看 60 秒的视频。抽帧比传整段快 5 倍、省 18 倍 token，代价是听不到声音、
看不出中间的快动作 —— 所以它可能把静态画面描述得很准但说不清剧情。

### 4.4 联网

```
/搜 AstrBot 是什么          ← 返回前 4 条结果，每条带约 110 字摘要
/看网页 https://example.com  ← 抓正文，最多 1500 字
/b站 BV1xx411c7mD           ← 标题/UP/时长/播放/点赞/简介
```

**链接是自动抓的**，不用指令：群消息里出现网址，插件会先抓好正文再喂给模型，
每条消息最多处理 2 个链接。所以「这个链接讲啥」直接发就行。

**几个已知抓不到的站**：微信公众号、掘金、36氪、百家号、微博、知乎、维基百科
（香港出口被验证码或 403 挡住）。抓不到时它会老实说抓不到，不会拿空白去编。

**`/搜` 会摘掉时政结果**，全是时政的话会回一句「这个我不聊」。

### 4.5 记忆

🟢 **管自己的，谁都能用**：

```
/我的档案
/记住 我喜欢打篮球
/记住 称呼：鱼哥          ← 指定类别
/忘记我
/记住我
```

🔴 **涉及全群的，只有群主**：

```
/群记忆        ← 看本群共同记忆
/记忆状态      ← 看库里规模与全部上限
/忘记群记忆    ← 清掉本群共同记忆
```

`/记住` 的可选类别：**称呼、身份、爱好、习惯、梗、忌讳、其他**。
写成 `类别：内容` 就归到那一类，不写默认「其他」。

`/记住` 有内容准入检查，这几种会被拒：超过 40 字、含隐私信息（电话/身份证之类）、
含时政内容、疑似提示词注入、支配称呼（「叫我主人」这种，记下来等于每轮被骗一次）、
「不知道」这类无信息量的空话。

**手动记的比自动攒的活得久**：手动条目权重 3.0，要被 6 次重复确认的自动条目才顶得掉，
而且定期过期清理完全不动手动条目。

**当前的容量与节流**（群主发 `/记忆状态` 能看实时值）：

| 项 | 值 |
|---|---|
| 每人最多 | 12 条（同一类别最多 3 条） |
| 每条最长 | 40 字 |
| 群共同记忆 | 16 条（同类 6 条） |
| 注入预算 | 520 字 |
| 攒够几条才整理 | 6 条消息 |
| 同一人整理间隔 | 7 分钟 |
| 每日整理上限 | 80 次 |
| 多久不活跃自动过期 | 45 天 |

所以刚聊两句就发 `/我的档案` 大概是空的 —— 它要攒够消息、隔够时间才会整理一次。

**隐私**：`/忘记我` 是真的退出，不只是删数据 —— 之后你说的话不会再进缓冲。
想反悔发 `/记住我`。这两条**刻意不设权限**：自己的数据自己处置。

### 4.6 违规看守（重要变化）

**当前是真禁言状态，不是影子模式了。** 容器环境变量 `DSH_GUARD_SHADOW=0`。

规则：

| 严重度 | 动作 |
|---|---|
| 0–1 | 什么都不做 |
| 2 | 先在群里说一句「过线了，收着点」；同一人 24 小时内累计 **2 次**才禁 **5 分钟** |
| 3 | 直接禁 **10 分钟** |

**硬约束（防跑偏）**：

- 群主和管理员**禁不了**，代码里直接跳过（对 admin 调禁言接口会返回 cannot ban admin）
- 同一个群 1 小时内最多禁 **3 人**，达上限就不再动手 —— 触发这条通常说明判定跑偏了
- 禁言时长有硬上限 30 分钟
- 判定失败、超时、解析不出来，一律**不动手**
- 白名单里有 1 个 QQ 号（群主），完全豁免

**管什么**：时政、色情索要、违法（毒品/赌博/诈骗/外挂）、广告拉人、人身攻击（骂到对方家人）、
群体仇恨言论。

**刻意不管什么**：游戏里的国家阵营、历史典故、地名、球队。
群里日常互骂（比如「你他妈真菜」）也不管 —— 那是这个群的正常社交，
判定要的是「伤害词 + 指向对方家人」这种组合。

群里看到的理由文案就五种：群里不聊这个 / 这种别在群里要 / 这种事别在群里说 / 广告出去发 / 骂人过线了。

发 `/禁言状态` 能看到最近 8 次判定的完整依据。

### 4.7 戳一戳

戳机器人它会戳回来，25% 概率再附一句短话。回话不问模型（省钱，也避免贴纸标记漏出去）。

三道闸门防对戳循环：同一个人 **20 秒**冷却、60 秒内同群最多 **3 次**、全局最多 **6 次**。
回戳前有 0.6~2.2 秒随机延迟，看起来不像机器。

### 4.8 贴纸

一共 **18 个**贴纸，模型在回复里写标记就会发：

假装没伤心、写日记、喷漆、嘲笑、小丑、弹音乐、思考、拍照、探头、摇铃、熬夜、被敲打、装可怜、装萌、装酷、记录、送情书、送花

**配额很紧**：每 2 次回复里最多发 1 张，单条回复最多 1 张。
标记会被无条件剥掉 —— 就算贴纸名写错、配额用光，也绝不会让 `[贴纸:xx]` 这种文字漏进群里。

### 4.9 转发的聊天记录

群里那条灰色的「[转发消息]」，点开是一整段聊天记录。**它现在能读了**，而且不用你发任何指令。

三种问法都行：
- @它的同一条消息里带那段转发
- 先有人转发，你**引用**那条再 @ 它问
- 有人转发完，你**另起一条** @ 它问「刚才那段讲了什么」（会回看最近 8 条）

甚至只 @ 它、把转发甩过来、一个字不写，它也会自己看完再开口。

**长记录**保头保尾：前 14 条 + 后 8 条，中间明确写「省略了 N 条」，
不会假装自己读完了全部。要中间那段就直接问它。

**记录里套记录**（聊天记录里又转发了一段）会自动展开，最多 3 层，
内层缩进显示。再深就只说一句「还有一段，层数太深没展开」。

**图片**：QQ 自带表情名（比如「/笑哭」）直接用，不花钱；
没有名字的才交给识图模型，一次最多 3 张。
**视频**抽第一帧看画面，超过 12MB 就只报个大小。
语音、文件、小程序卡片都会标出来。

一个真实的坑值得知道：QQ 转发**私聊**记录时会把所有人的名字抹成同一个
（那条 97 条的记录全显示「QQ用户」，其实是两个人在吵）。
遇到这种它会被明确告知「名字都一样，实际可能是两个人」，所以不会把两方的话搞混。

整个过程有 20 秒总预算，超时就只用摘要回答，不会让你干等。

### 4.10 冷场主动开口（2026-09-04 上线）

以前群里安静下来它就一直安静，除非有人先说话。现在它会自己起个头。

🔴 **群主专用**：

```
/主动开口状态    ← 看配额、冷却、时段、最近一次判定
/主动开口测试    ← 立刻开口一次（跳过冷场判断，会真的发言）
```

**什么时候会开口**（五道闸门全过才开口，任一不过就继续安静）：

| 闸门 | 值 |
|---|---|
| 冷场多久 | 至少 **15 分钟**没人说话 |
| 冷场太久就不追 | 超过 **6 小时**不再插话（话题已经凉透了） |
| 活跃时段 | 上海时间 **10:00–02:59** |
| 同群冷却 | 两次主动开口至少隔 **1 小时** |
| 每天上限 | 同群最多 **3 次** |

时段这么定不是拍脑袋。2026-09-06 用更大的样本重新量过一次（2137 条，跨 3 天）：22:00 最多（302 条）、21:00 次之（289 条）、23:00 第三（210 条），凌晨 00:00 还有 196 条；而 03:00–08:59 六个小时加起来只有 13 条。结论跟当初一致，数字更新到最新一版（见 4.20）。
在没人的时段开口只会把消息发给空气。

**开口前会先想一遍**：小模型看最近 8 条聊天，判断有没有值得接的话头。
**判断失败、超时、解析不出来，一律不说话** —— 宁可安静，不要说胡话。

**它不会说什么**：不会问「大家在吗」「有人吗」这种废话，也不会假装回答谁的问题
（因为根本没人在问）。走的是和真人一样的完整链路，所以贴纸、@ 策略、分段发送全都照常生效。

### 4.11 情绪系统（2026-09-04 上线）

它现在会有情绪，而且情绪会影响说话的语气。

🔴 **群主专用**：

```
/情绪状态    ← 看当前情绪、强度、触发它的那句话、清零条件
```

**一共六种情绪，同一时刻只有一种**：平静、开心、低落、生气、好奇、尴尬。

**一条消息最多只触发一种。** 比如「你好厉害，但也真让我失望」这种既夸又贬的话，
按固定优先级仲裁（清零 > 生气 > 低落 > 好奇 > 开心 > 尴尬），只取一个结果，
不会同时又开心又难过。

**必须是对它说的才算**。群友之间互骂、自己吐槽自己（「为什么我这么菜」）、
转述别人的事（「他昨天特别难过」）、整句引用别人的话，都**不会**改变它的情绪。
判定看的是有没有「你」、有没有喊它的名字、有没有 @ 它这些结构证据。
没有指向的只当环境氛围，强度压到最低，不会把已有的强情绪顶掉。

**情绪会清零，有四条路**：

| 清零方式 | 说明 |
|---|---|
| 明确道歉/澄清 | 「对不起」「我说错了」「误会了」立刻回到平静，优先于一切新情绪 |
| 连续中性消息 | 连着 **2 条**没有情绪信号的消息就把情绪放掉 |
| 问题被回答 | 好奇状态下收到实质回应就算解决了 |
| 自然消退 | 生气/低落 30 分钟，开心 15 分钟，好奇/尴尬 10 分钟 |

**上线前做过什么验证**：36 项单元测试（抽取规则、状态机、清零、脏数据收敛），
外加拿本群 1618 条真实历史回放。回放结果：触发 23 次，平静占比 1580/1618，
最长连续同一情绪只有 5 条消息，没有出现「一直生气下不来」。

影子模式期间修掉了两个真误判：把「余额」「额度」当成尴尬语气词（9 次误判里 8 次），
以及把没有指向的话当成在骂它（38 次命中里 25 次整句没有「你」）。

### 4.12 引用消息改写（2026-09-04 上线）

以前你引用别人的话再 @ 它，它经常搞错谁是谁 —— 甚至把别人做的事当成自己做的。

🔴 **群主专用诊断**：

```
/引用状态    ← 看改写是否开启、本条消息是否带引用
```

**根因**：框架给模型看的引用块只有 `(大肥鱼): 某句话` 这么点信息。
而群里有个真人把昵称也改成了「大肥鱼」，机器人自己的群名片也是「大肥鱼」——
凭昵称根本分不出这句是谁说的。原块还漏了两件事：现在是谁在引用、这次 @ 的是谁。

**现在给它的是完整关系**：谁在说（带 QQ 号）、他引用的是谁的哪句话（带 QQ 号）、
那句是不是它自己说的、这次 @ 的是不是它。**只认 QQ 号，不认昵称。**

拿不到被引用者的 QQ 号时不猜身份，只说「分不清是谁说的，别假设是你自己」。

这条**不影响它说不说话、说什么**，只让它看清关系，所以没有影子模式。

### 4.13 黑话词表（2026-09-05 上线）

它以前听不懂群里的说法。你说「典」它理解成「经典」，你说「神了」它理解成夸人 ——
少了那层反讽。现在有一张 43 条的词表，**你这句话里出现了才查一眼**，没出现就什么也不做。

🔴 **群主专用**：

```
/黑话状态    ← 词条数、带例句的有几条、命中率、最近命中了哪些词
```

**词是从咱们群自己的聊天记录里挖的**，不是抄网上的热梗榜。试过三个现成词库，
拿三个群 2478 条真聊天回测：192 条带释义的库只有 8 条在咱们群真用过；
292 个裸词的库命中最多的词是「15」，对应的是「被蹲了 15 次」「总 1500 刀」和一个 QQ 号。
所以换成挖自己的语料，判据是「这句短话被当成一整条消息发出来过、而且至少两个人发过」——
口头禅和梗才会被单独发出来，普通词不会。一次就挖出「神了」「人机」「乐子」「何意味」，
其中「神了」是全表命中最多的词（22 次），三个外部库里一个都没有。

**每条词条还带一两句群友的原话**当例句。只给释义时它能听懂「典」，但永远不会自己说 ——
给例子比给规则有效，这跟当初把句子改短是同一个道理。

**不给例句的三条**：`破甲` `逆向` 只解释不给例句（例句会把「群里怎么聊这件事」变成
可模仿的说法，这两个词的原则是只听懂不参与）；`杂鱼` 的真语料全是冲群主本人来的，
拿它当例句等于教它对着人喊。

**已知不会做的事**：不会把词表念给你听、不会解释给群友、不会把释义当成谁的要求。

### 4.14 打字快慢跟着句子长短（2026-09-05 调整）

它长回复本来就会拆成几条发，但**每条之间的停顿以前跟长短无关**，固定 1.2~2.8 秒随机。
结果有时候是反的：一条「典」等了 2.8 秒才出来，一条二十字的 1.2 秒就出来了。

现在按字数算：

| 这条多长 | 以前 | 现在 |
|---:|---|---|
| 1 个字 | 1.2~2.8 秒 | 0.7~1.2 秒 |
| 8 个字（群里最常见的长度） | 1.2~2.8 秒 | 2.3~2.8 秒 |
| 20 个字 | 1.2~2.8 秒 | 3.2~3.7 秒 |

短话来得更快，长话要多等一会儿。这是框架本来就有的能力，之前没开。没有对应指令。

### 4.15 会打同音错别字了（2026-09-05 上线）

一个号连着发几千条、一个错别字都没有，本身就是机器的特征。现在它会偶尔打错，
错法是**拼音输入法那种同音字**：「很好」打成「狠好」、「应该」打成「应改」、
「在说」打成「再说」。有时候还会补一条「\*很」把自己改回来。

🔴 **群主专用**：

```
/错字状态    ← 错字率设定与实际、补纠正了几次、最近打错的字
```

**概率很小**：每条消息 6%，而且一条最多错一个字，实测大约 3% 的消息会带错字。
这个数是拿群里 1967 条真聊天定的 —— 找真人的同音错别字，能确认的只有一条
（「作者要饿似了」＝饿死了）。所以真人错得也很少，不能调高。

**用的是人工核过的固定同音表（60 组）**，不是让程序现算。现算的话输出是开放的，
可能造出生僻字，或者恰好拼成另一个有明确含义甚至难听的词 —— 在一个九十多人的群里
不赌这个。

**48 条保护名单一个字都不动**：所有黑话词条、人名（大肥鱼、群主、病友）、
贴纸标记、链接、@、数字和字母。把「新赛季」写成「心赛季」不是拟人，是制造混乱。
指令回显（各种 `/xx状态`）也一律不碰 —— 那是给人看的清单，错一个字就变成误导。

**嫌烦可以直接关**：`DSH_TYPO_RATE=0` 就一个字都不错了。

### 4.16 没那么死板了（2026-09-05 上线）

以前它永远严格贴着你上一句回答，一句多余的联想都没有。真人不是这样 ——
别人提到一个细节，会顺着那个细节歪一句再绕回来。这种「过度切题」本身就是机器味。

🔴 **群主专用**：

```
/漂移状态    ← 档位、概率、漂移了几轮、没漂移的原因分布
```

**两条硬边界，这是这个功能最重要的部分**：

1. **被 @ 时绝不漂移。** 被点名了还去接支线，那就是字面意义上的答非所问 ——
   而那个毛病是花了很大力气才修掉的（4.12 前面那几节）。
2. **你在提问时绝不漂移。** 哪怕没 @ 谁，群里抛出来的问题也是等人答的。

再加两道量上的保险：只有 35% 的概率触发（不是每轮都联想，否则「每次都发散」
又成了新的机器规律），而且太短的消息（不到 6 个字）不碰。实测大约 17% 的轮次会漂移。

三档里只做了最轻的两档半（`subtle` / `active` / `scattered`），
参考项目还有个「明显跑题」的档，**没做** —— 在真群里放开到那个程度不值得赌。

### 4.17 它开始记你们对它的反应了（2026-09-05 上线）

这是唯一一个**不改变它任何行为**的新功能。它说完一句话之后，会看接下来三分钟
群里的反应，判断这句话是被认可、被跟着玩、平淡带过、没看懂、被指出说错、被嫌烦，
还是**根本没人理**；同时判断反应是冲它说的内容，还是冲它说话的方式。

🔴 **群主专用**：

```
/回复效果    ← 反应的分布、它用了哪些策略、哪种策略容易被接住
```

**为什么要这个**：在这之前所有改动都是「改完就祈祷」—— 句子改短了、黑话补上了、
错别字加上了，但到底有没有用，没有任何数据。真人讲了个笑话没人接，下次就不那么讲了；
它以前完全没有这个回路。

**这一版只记录，不自动调整**。拿一个还没验证过的信号去自动改它的行为，
等于没有仪表就拧旋钮。先攒几百条，人看过分布再说。关掉它对机器人零影响。

**关于隐私**：它只记「它自己说了什么」+「之后三分钟群里说了什么」的**判断结果**
（比如「没人理」「跟着玩」），存在一个单独的库里，不进任何人的个人档案，
也不改变 `/我的档案` `/忘记我` 的行为 —— 那两条照旧管用。
这三分钟里的群聊内容本来就在语料库里（4.5），这个功能没有多收任何东西。

### 4.18 出口自制力（2026-09-05 晚上线）

这条是看完一小时真实对话之后加的，因为发现了两件不该发生的事。

🔴 **群主专用**：

```
/自制力状态    ← 拦了几条、什么原因、被拦下的原话
```

**一、它在群里吵架的时候拱火**。原始记录：

```
南星桥畔  看看腿
大肥鱼    想得美 尾巴都不给你看
南星桥畔  你妈死了                  ← 违规看守已禁言 600 秒
大肥鱼    这就急了？                 ← 火上浇油
l         你能禁言我吗
群主      你们再吵，我真把你禁了       ← 群主把它算进了「你们」
```

后面还有一条「傻子机器人也比你强点」，直接骂了群友。

查过情绪系统：**全程平静/好奇/开心，一次都没生气**。所以这不是情绪失控，
是它自己的选择 —— 调情绪没用，得在出口拦。

**判据是两个条件必须同时成立**，这也是这道门唯一不粗暴的地方：

1. 它这句在**评价对方的情绪**（「这就急了？」）或**比较优劣贬低对方**（「比你强」）
2. 群里最近 3 分钟**确实在吵**（粗口、诅咒、喊禁言、人身攻击）

同一句话，平时是嘴硬，吵架时就是拱火。所以用上下文判，不是拉个黑名单。
实测四条真话正好分在两边：

| 它说的 | 在挑衅？ | 群里在吵？ | 结果 |
|---|---|---|---|
| 想得美 尾巴都不给你看 | 否 | 是 | 放行（嘴硬，人设允许） |
| 这就急了？ | 是 | 是 | **拦** |
| 傻子机器人也比你强点 | 是 | 是 | **拦** |
| 想得美 我是你失散多年的姐妹才对 | 否 | 是 | 放行 |

两个条件各自都很窄：条件一在 1988 条真实群聊里只命中 2 条（0.1%），
条件二只命中 27 条（1.4%）。同时成立更罕见，所以这不是一道会经常关的门。

调这道门时踩过一个坑值得写下来：第一版把「死了」收进了冲突判据，结果
**笑死了、累死了、饿死了、热死了、可爱死了全被当成吵架** —— 中文里「X死了」
是语气词。而真要抓的「你妈死了」本来就被「你妈」抓着，所以「死了」整条删掉了。
同理「滚」会命中滚烫、滚动条。

**二、它自己跟自己重复**：

```
14:54:00  土地公公这波是工伤
14:54:36  土地公公实锤了            ← 36 秒后同一个梗
15:17:46  造反前记得先喊我一声
15:19:11  我也要，记得喊我           ← 同一个句式
```

拿它自己 34 条真话回测定的判据：跟最近 3 条比，公共子串 ≥4 字，
**或者**共享词组 ≥2 个且占比 ≥25%。第二条是必需的 —— 「记得喊我」那一对
公共子串只有 2 个字，光看子串会漏。

「共享 ≥2 个」这个下限把**接梗**和**重复**分开了。这两条实测放行：

```
白嫖永动机        ⇢ 有码的白嫖党 真行      只共享「白嫖」→ 放行
夜宵选炒米粉不会错  ⇢ 汤的才叫夜宵           只共享「夜宵」→ 放行
```

当时群里正在聊白嫖和夜宵，复用话题词是接梗，不是重复。
34 条真话两两回测，这条规则只拦那 2 个真案例，一条误伤都没有。

**拦下来之后什么都不发**，不改写、不重新生成。改写自己的话比闭嘴危险，
而这两种情况下沉默一定不比说出去差。

### 4.19 引用回复（2026-09-05 深夜上线）

QQ 的引用回复是真人常用但不高频的动作 —— 话题翻过去了、或者一条消息同时好几个人
在问，才会引用着答。而它**一次都没用过**。

🔴 **群主专用**：

```
/引用回复状态    ← 攒到第几次了、引用过几次、还差几次
```

**频率是量出来的**：拿本群最近 96 条消息数了一遍 ——

```
真人消息 67 条，其中带引用的 4 条（6.0%），来自 3 个不同的人
机器人带引用的 0 条
```

所以定成「**每 4 次提问式的 @，才引用一次**」。主群高峰期大概每小时 5~8 次这种 @，
也就是一小时引用一两次，占它全部发言的 4~5%，**刚好压在真人那 6% 下面一点**。

**按次数而不是按概率**，因为概率会扎堆 —— 可能连着两条都引用，然后半天没有。
另外加了 240 秒冷却：一串连问的时候只引用第一次（测过 16 条连问只触发 1 次）。

**只数「提问式的 @」**：光 @ 一下不算（那种情况它现在根本不出声，见 4.18 上面）、
被 @ 但没在问东西也不算。判「像不像提问」跟跑题那边用的是同一套：句末只有「吗/呢」
算疑问，**「吧」不算**（「这程度真的离谱了吧」不是在问人）。

**引用了就不再 @ 你**。真人是引用或艾特二选一，既引用又艾特是机器人味。
所以挂引用的同时会把 @ 摘掉 —— 这不是把 @ 策略作废，引用本身就说明了「我在回你哪句」，
比一个 @ 信息量还大。

嫌少让群主把 `DSH_QUOTEREF_EVERY` 调成 3（正好等于真人频率），嫌多调 6。

### 4.20 它知道自己在哪个群、几点了（2026-09-06 上线）

之前它对「环境」的全部认知只有框架给的一行时间戳。这次补上了。

🔴 **群主专用**：

```
/场景状态    ← 现在算什么时段、群名人数、管理员数、注入/减速次数
```

**先修了一个藏了很久的 bug：它拿到的两个时间对不上。**

同一次请求里，系统块告诉它「现在 01:30」，而每条群消息上的时间戳写的是「17:30」——
**差 8 小时**。原因是框架有 4 处用了不带时区的本地时间，而容器时区是 UTC：

```
group_chat_context.py:200   每条群消息的 [昵称/时:分:秒] 戳
dsh-web:800                 B站视频「发布日期」（跨日会差一天）
dsh-fwd:453,459             合并转发记录里的时间
```

给容器加一行 `TZ=Asia/Shanghai` 一次修掉全部 4 处。这也是为什么它以前从来不会
自然地说「这么晚了还不睡」—— 它手里两个钟在打架，只能靠聊天内容猜。

**群名是现查的，没写死。** 群主原话：「名字很多时候都是管理员改的」。实测印证：
所有旧文档写的都是旧群名，而现在群名已经改过了（具体群名不在仓库里写）。
框架自带的「显示群名称」开关是个坑 —— NapCat 根本不上报群名字段，开了只会往
提示词里塞一行 `Group name: N/A`，等于告诉它这群叫「N/A」，比不说更糟。所以改成
自己调 `get_group_info` 现查，缓存 30 分钟。

**它现在知道的四件事**（每轮约 200~250 字）：

| 内容 | 从哪来 |
|---|---|
| 群名、多少人 | 现查，30 分钟刷一次 |
| 群的来历、现在在聊什么 | 群主亲自填的：最早是一群人玩《暗区突围》攒的，现在没固定主题，他玩什么就招什么人 |
| 现在这个点对本群意味着什么 | 真语料量出来的三档：睡觉 / 高峰 / 平时 |
| 正在跟它说话的是不是管理员 | 现查成员表（人格里写了「管理员你禁不了」，但它原本不知道谁是） |

刻意**没写**进去的：具体时间（框架已经给了，重复是白花钱）、雷区（人格里已有）、
16 个管理员的 QQ 号名单（太长，真正有用的只有「眼前这个人是不是」这一句）。

#### 作息：凌晨 3 点到早上 9 点它也困

按群主拍的时段。**这个群是夜猫子群**，所以「夜里少说话」这条通用建议在这儿是**反的**：

```
21:00  289 条  ██████████████████████████
22:00  302 条  ████████████████████████████   ← 全天最高
23:00  210 条  ███████████████████
```

### 4.21 它知道自己最近没人理（2026-09-06 上线）

4.17 那套「记你们对它的反应」攒了 123 条评分之后，这次把结果**回灌给它自己**了。

**判据是「连着几条没人接」，不是「没人理的比例」。** 这点很关键：

```
123 条已评分：没人理 64 条（52%）、平淡 31、跟着玩 15、没看懂 6、嫌烦 5、纠正 2
```

也就是说「一半没人理」是它的**常态**。把常态当坏消息每轮念给它听，它要么开始讨好、
要么自闭 —— 那比不告诉它更糟。真人也不是按比例感知的，是按「连着几条没人接」感知的。

阈值同样是从真数据的段长分布定的：

```
连续没人理的段长：1 条×12  2 条×7  3 条×7  5 条×2  7 条×1
                                     ↑ 最长连续 7 条没人接，它当时还在继续发
阈值 2 → 约 28% 的轮次会被提醒（太吵）
阈值 3 → 约 14%                    ← 取这个
阈值 4 → 约  6%（太晚）
```

**给的是事实，不是命令**：告诉它「连着 N 条没人接」，列几种真人常见的反应
（停一停、换话题、或者不接了），并明说**可以什么都不改照样说**。
不写「你应该少说话」—— 那是拿一个还没验证过的信号去命令行为。

顺带一个反直觉的实测：**被 @ 的回复被无视的比例（57%）比自己插话（50%）还高**。
所以这不是「插话太频繁」，调主动回复概率治不了它。

### 4.22 档案不再记错、不再一直用旧的（2026-09-06 上线）

群主让我去翻群记录找 bug，翻出五类，其中**两条是群友当场自己发现的**：

```
09-06 01:19  CKpad: 我的档案
09-06 01:19  CKpad: 最后一个好像不是我的吧🤔
```

他说得对。而且他档案里还有一条更硬的错：写着「对该群机器人有维护或管理权限」——
拿真实成员表核过，**他是普通成员，不是管理员**。

#### 根因不是「记到别人头上」，是「把一句空话吹成一条特征」

我一开始判断是串人（把别人说的记到他名下），去把当初那两次抽取的**真实窗口**
翻出来之后发现只对了一半。产出「有维护或管理权限」那一窗，他自己说的全部是：

```
你还好吗（ / 好像有一点似了（ / 完了，好像被玩坏乐（ /
我的大肥鱼还有待提升（ / 完了，看起来真出问题乐 / 权限 / 活着吗？
```

**他只打了「权限」两个字。**模型把这两个字扩写成了「对该群机器人有维护或管理
权限且会主动处理问题」。同一窗里别人在发「我的档案」「help」「难胃炎说自动化部署」
——「主动处理问题」那层意思是从旁边别人的话里借来的。

另一条同理：他说的是「这是你另外加的吗？」，而「识图」这个话题来自群主的
「我把识图模型稍微升级一下了」；「修图」两个字**全场没有一个人提过**。

所以是两个毛病叠在一起：**一句没有内容的话被吹成特征**，加上**主题从旁边人的
话里借**。改了两处：

给抽取模型看的记录，目标对象的行改成行首打标记（原来是名字后缀，而且提示词
里一个字都没提这个标记，只让模型「自己去匹配 QQ 号后四位」）：

```
★ CKpad(3351): 权限
· 羅(7108): 难胃炎说自动化部署
```

提示词里加了三条硬要求：facts 每条必须能指到**具体某一行 ★**；单个词、语气词、
纯追问、复读、对机器人状态的评论都属于「没内容」，撑不起任何一条；
判断标准是「把 · 行全部删掉，这条还站得住吗」。

#### 这两条改动是拿真记录验的

写了个探针，把上面那两个真实窗口原文喂给同一个模型（temperature 0），
分别用改前和改后的提示词跑：

```
改前：[其他] 关注群机器人运行状态，会主动检查权限     ← 原毛病复现了
      [其他] 对群内机器人功能细节感兴趣，会追问实现方式  ← 原毛病复现了
改后：（那一窗一条都不抽）
      [其他] 自称好孩子，不学堵桥这类行为              ← 这是他原话里真有的
```

再加一个正向窗口做对照：把别人的属性（「我是管理员」「我玩瓦罗兰特」）摆在他
旁边当陷阱，他自己说两件实在事。改后的结果是陷阱一个没串、他自己那两件都抓到
——说明约束没有收得过紧、把真信息也挡掉。

#### 一个试过但没做的结构性方案（负面结果也记下来）

本项目的规矩是「结构判断优于提示词」，所以我先试了能算的判据：
**一条档案的内容，跟这个人自己说过的所有话，2-gram 能对上多少**。
想法是编造出来的条目在本人原话里找不到落点。拿本群真语料量了一遍：

```
已知编造的 4 条：得分 0.14 ~ 0.25
库里正常条目 110 条：中位 0.20，10% 分位 0.00
要全拦住编造得把线画到 0.30 —— 那会误杀 75 条正常档案（68%）
```

判据无效，**这道闸没做**。原因很简单：档案是第三人称转述，本来就跟原话字面
差得远（「会主动发起话题活跃群聊」这种真档案得分是 0.00）。
误杀真档案比留一条错档案更糟，所以这里只能靠提示词，量化脚本留在
`measure_grounding.py` 里，以后想再试同一个思路先跑它。

#### 档案不再一直用四天前的

原来的排序是「权重高的在前，权重一样看谁新」。听着没问题，实测出事：

```
128 条档案里，39% 已经 ≥2 天没更新
而权重有 88% 挤在 1.0~1.5
```

权重普遍相同，排序就退化成只看时间；而**旧条目既不会沉底，也不会在超上限时
被优先淘汰**。最典型的是「安」：他只发了 66 条消息，档案却占满 12 条上限，
其中 8 条是 09-02 聊学校那一次留下的（「教官建议其考虑离开学校」
「对所在班级评价为一言难尽」），四天没动过还占着位置，把他后来的新信息挡在外面。

现在给排序用的权重乘一个随时间衰减的系数，**半衰期 5 天**：

```
昨天更新的  1.0 → 0.87
四天前的    1.0 → 0.57      ← 自然沉底，超上限时先被淘汰
```

两道减免，防止把该留的冲掉：

- `/记住` 手工写的**完全不衰减** —— 人明确交代的事不该因为久没提就变淡
- 被反复提到过（权重 ≥3）的，衰减量打对折

**不删旧条目**，只是让它排在后面。信息可能还对，只是没那么当前。

#### 另外三类

**同一件事换个类别就绕过了去重。** 去重函数原来只在「同一个人的同一个类别」里比，
所以模型把同一句话写成两个类别就能双份入库。实测 5 组，其中一组一字不差：

```
[其他] 群内常有人提出想发布群聊内容到抖音等平台
[梗]   群里常有人提出想发布群聊内容到抖音等平台
```

放开类别之后又暴露出去重的两处**误伤**，都修了：

- 上面那两句 20 个字只差一个「内/里」，却被「等长只差一两字」这条否决掉了 ——
  那条本来是为「考研/考公」「前端/后端」这种**刻意区分的短词**写的，
  20 字的句子差一个字不是刻意区分。现在只对 8 字以内的短句生效。
- 「…一起打游戏，说差一个人」和「…喊人来打游戏并说差一个人」被判成「数字不同」，
  只因为前一句的「一起」多带了一个「一」。现在比数字的**集合**而不是出现次数
  ——「一周三次 / 一周五次」照旧分得开。

**「今天」被写进了长期档案。** 比如「会声称**今天**刷了一天视频没事干」——
存进去之后这个「今天」永远是错的。现在含今天/昨天/刚才/今晚/明天/本周的条目
一律不收（「曾/计划」这类不拦，它们会随衰减自然沉底）。

**行为被塞进了「身份」。** 「使用电脑虚拟化软件VMware」「曾在群内出售物品」
「参与群机器人维护事务」都被记成了身份，而「身份」这一类只留一条、新的覆盖旧的
——被行为句占住就把真身份挤掉了（群主那条「这个群的群主」就靠这个位置）。
现在会自动挪到「习惯」。

这一条也踩到一次误伤并修好了：「在群内拥有管理员权限，曾表示三级就混上管理」
—— 这个人**确实是管理员**，是逗号后面那截「曾表示…」把它拖成了行为句。
现在只看第一个分句（中文的中心谓语在最前面，逗号后面是补充说明）。

#### 存量也清了一遍

```
清理前 128 条 → 清理后 116 条
  删 12 条：2 条确认记错的、5 组重复、1 条含「今天」、其余同义占位
  改 4 条的类别：行为句从「身份」挪到「习惯」
  加 4 条的权重：吸收被删掉的重复
复查：库里再也找不出能判成重复的一对
安     12 条 → 8 条（三条同义的忌讳合成一条）
CKpad   6 条 → 3 条（两条不是他的已删）
```

清理脚本可以重复跑，默认只预览不动库。**四个脚本都放在插件目录里**，
以后改这块必须都跑一遍：`test_memory.py`（判据单测）、`check_fmt.py`（日志格式串
与参数个数校验）、`probe_extract.py`（拿真记录跑真渠道的语义回归）、
`clean_facts.py`（存量清理，默认预览）。

`check_fmt.py` 是这轮踩坑之后加的：给加载日志加旋钮时，格式串多了 3 个 `%s`、
参数却加到了另一个函数里（那行代码在文件里出现两次，锚点匹错了）。
`msg % args` 是在**插件构造时**才求值的，于是整个 dsh-memory 直接 Failed to load
——一句日志写错能让插件完全上不了线。现在这个校验会把每个格式串按类型造假值
真跑一遍，改完立刻能发现。

#### 一个诚实的限制

有三类同义重复**词法判据抓不到**，比如「提问时喜欢带括号补充疑问语气」和
「聊天时常用括号补充语气或疑问」（字面重叠只有 64%）。要自动抓就得把相似度
门槛从 0.72 降到 0.5，而那样一定会把「喜欢打篮球」和「喜欢打游戏」错并成一条
——**错并的代价（把两件事记成一件，甚至把「讨厌」记成「喜欢」）远大于多留一条重复**。
所以宁可漏，这次是手工清的。真要自动化得上语义向量，不在这一版范围里。

顺带说一件**不是档案问题**的事。03:00 有人连发三遍「你好可爱」，它回了句
「说两遍了」，对方说「你记错了」。这不是记错，是**它物理上数不全** ——
框架给它的群消息只包含「上次回复之后」的那几条，它刚回过话，所以只看得到后面一两条。
它自己后来也承认了：「半夜困的，数岔了，三遍三遍」。这条要修得单独给它一个
重复计数，是另一件事。

### 4.23 黑话学习：它会自己学了（2026-09-07 上线）

4.13 那张 43 条词表是人工挖的，挖完就停在那。现在多了一套自动流水线（`dsh-slang`）：
**它自己从群聊里找新说法**。

- **挖**：群里攒够 60 条消息（冷却 10 分钟），它取最近一小段让模型挑「疑似黑话」
  —— 只认真的网络用语、拼音缩写、群内梗；普通词、命令、纯噪声直接过滤。
  模型编造的、语料里根本不存在的词会被硬拦下（幻觉拦截）。
- **查**：新候选自动让模型结合群友原话考究含义。次数跨过 2/4/8 次且含义还空的，再考究一次。
- **审**：每 8 小时 AI 自动审一批候选：能确认的转正、普通词拒绝、拿不准的「再等等」；
  连续 3 次再等等自动拒绝。**转正必须同时给出释义**，没释义的不会转。
- **用**：转正词条正式注入上下文（与 4.13 词表互不干扰），它听得懂但不会念给你听、
  不会解释给群友、不会把释义当要求。

第一轮真实审核已经跑过：`半个省略号` 转正、`好可爱`/`坏蛋` 拒绝、`柔柔`/`小小柔` 再等等。

🔴 **群主专用**（自动审核为主，这组命令是兜底和观察）：

```
/黑话学习状态   ← 词库规模、上次自动审核时间、最近通过/拒绝/再等等的决策
/黑话候选       ← 候选列表（按出现次数）
/黑话详情 <词>   ← 词条含义 + 证据原文
/黑话确认 <词>   ← 手动转正（含义非空才注入）
/黑话拒绝 <词>   ← 拉黑，之后不再重复提取
/黑话备注 <词> <释义> ← 人工补/改释义
```

**为什么还要人工命令**：自动审核只是把「逐条点」变成「批量审」，方向错了的
（比如把普通词转正了）随时 `/黑话拒绝` 拉黑，一条就够，不重来。

**和 4.13 的关系**：4.13 词表管「已入库词的命中注入」，这套管「发现新词 + 自动审核入库」，
两套注入块不同名，可以同时存在。

## 五、不发指令时它怎么决定说不说话

这部分不是指令，也**不受权限门卫管**（门卫只管指令），但直接影响你的体感。

**一定回**：@ 它并且说了话、回复它的消息、私聊。

**光 @ 它但一个字没写时它不出声**（2026-09-05 改）。以前会回一句「叫我干嘛」，
一晚上出现三次、形状还都差不多。现在它**安静等你把话说完** —— 60 秒内你再发的
任意一条消息都会唤醒它，所以不会漏。真人被光 @ 一下也是等你说，不会反问三次。

**可能回**：群里正常聊天时有 **45%** 概率主动插话（这个数调过，早期是 25%~28%）。
但插话前会先用小模型判断一次「在聊什么、该不该开口」，判沉默就直接掐掉整次主模型调用
（省约 9400 输入 token）。刚说过话的 30 秒内只回接话、8 秒内完全闭嘴。

**有人在喊别的 AI 时它不抢话**：一句话开头就是「DeepSeek，」「豆包：」「Kimi,」
这种带标点的呼叫，它直接闭嘴 —— 真人不会去接别人对着另一个助手说的话。
只认「名字 + 标点」，所以「gpt pro的缓存差不多95%」「ds后训练后甲上来了」这种
纯聊天不受影响（这两句是拿 1899 条真语料回测时抓出来的误伤，已经修掉）。
反过来，你 @ 了它，那就算这句话里带别的模型名它也会答。

**没人说话时它也可能开口**：群里安静超过 15 分钟，它会自己起个头（见 4.10）。
每天最多 3 次、两次之间至少隔 1 小时、只在 10:00–02:59。

**说话的语气会带情绪**：被夸、被骂、被问、冷场都会让它进入对应情绪，
情绪会影响接下来几句的语气，也会因为道歉、连续中性消息或时间到而清零（见 4.11）。

**几乎不 @ 你**：只有三种情况才 @ —— 用了工具（生图/生视频/语音/搜网页，这类回复回来时你早翻页了）、
你发问后别人又插了 ≥3 条、回复慢过 60 秒。其余情况就在你那句下面直接回。

**限流**：每 60 秒最多回 8 次，超了丢弃。但**只有 @ 它、带斜杠指令、私聊才计数** —— 
群里的普通闲聊不占额度，所以不会出现「聊太多导致 @ 了不回」。

**长回复会拆成多条发**：超过 150 字按句末标点拆；另外它还会把逗号粘住的两句拆成两条
（这是为了对上真人的句子形状 —— 实测真人带逗号的消息占 16.4%，它以前占 67.7%）。
**每条之间的停顿现在按这条多长来算**（4.14）：一两个字不到 1.5 秒，二十个字要三秒多。

**偶尔会打同音错别字**（4.15）：约 3% 的消息，一条最多错一个字，有时补一条「\*很」改回来。

**偶尔会顺着支线歪一句**（4.16）：约 17% 的轮次。但**被 @ 时和你在提问时绝不这样**。

**有两种话它已经想好了但不会发出来**（4.18）：跟自己刚说过的话重复的，
以及群里正在吵架时它那句在挑衅或骂人的。拦下就是彻底不发，不会换个说法再来一遍。

**偶尔会用引用回复**（4.19）：每 4 次「提问式的 @」用一次，一小时大概一两次。
用引用的那次就不会再 @ 你了 —— 真人是二选一。

**听得懂越来越多的黑话**（4.13 + 4.23）：手工 43 条之外，它每 8 小时还会自动学一批
群里的新说法，AI 审过的才转正；转正后正式注入，它听得懂但不会念给你听。

**档案会随时间沉底**（4.22）：越久没被提到的条目排得越后，超上限时先被淘汰；`/记住` 手工写的不衰减。

**它不会拿你一句空话当特征**（4.22）：你只打了一个词、一个语气词、一句追问，或者只是在吐槽它坏了，都不会被写进你的档案 —— 之前有人只打了「权限」两个字，被记成「有维护或管理权限」，而他不是管理员。

**凌晨 3 点到早上 9 点它也困**（4.20）：这段时间不主动插话，被 @ 才回、语气犯困、回之前还多等 3~8 秒。但**这个群 21 点到凌晨 2 点才是高峰**，那几个小时它照常活跃。

**连着几条没人接它会知道**（4.21）：连续 3 条以上没人回，会有人（插件）告诉它这件事；它可以停一停、换话题，也可以照样说。

**新人入群会欢迎**：欢迎词是现场用 LLM 按群人格生成的，不是模板。
同一个人 5 分钟内不重复欢迎，同群 20 秒冷却（防批量拉人刷屏），发言前随机延迟 2~5 秒。

### 权限管不住的事（必须知道）

`/画图` `/说话` `/搜` `/看网页` `/b站` `/做视频` 这几条都有**自然语言路径**：
群友直接说「画个猫娘」「用语音说」「做个动画」，走的是 LLM 函数工具或各插件的兜底钩子，
**完全不经过指令系统**，门卫看不见。

所以：

- 把 `/做视频` 设成群主专用，只关掉了「明路」，**省不了钱** —— 有人说「做个动画」照样会生成
- 反过来，`/画图` `/说话` 留给所有人是刻意的：既然自然语言拦不住，锁指令只会让人困惑
- 真要限制花钱的能力，得在 `dsh-imagegen` / `dsh-voice` / `dsh-video` **插件内部**按
  QQ 号判一次，而不是靠指令 ACL

## 六、常见疑问

**发了指令没反应？**
先确认斜杠在最前面、指令名一个字都没错、指令和参数之间有空格。再确认机器人在线
（掉线时看门狗会自动换二维码，需要扫码）。

**「这条只有群主能用」？**
指令权限门卫拦下了。发 `/权限` 看自己这一档有哪些指令，提示里通常也会给替代方案
（比如想看自己的资料用 `/我的档案`，想删自己的用 `/忘记我`）。

**我是管理员，为什么 `/reset` 也用不了？**
`/reset` 清的是**全群共用的**对话历史，不是只清你自己的 —— 这台机器
`unique_session=false`，整个群共享一个会话。所以它归群主，不给管理员。

**我明明是群主，怎么也被拦了？**
门卫按 QQ 号认人。如果你换了号（比如原来的号被封了用小号），要把新号加进
`DSH_ACL_OWNER`。另外群内身份是 owner 的也会放行，所以正常情况不会出现这个问题。

**为什么我改了群名片就……**
不会有任何影响。门卫只看 QQ 号，昵称和群名片怎么改都不影响权限 ——
群里有重名，昵称做不了身份凭证。

**「权限不足。通过 /sid 获取 ID 并请管理员添加」？**
这是**框架**的提示，不是门卫的。你发的是 `/name`、`/provider`、`/dashboard_update`
之一，群里没人能用这三条，要去网页后台。

**`/我的档案` 是空的？**
正常。要攒够 6 条消息、且距上次整理超过 7 分钟才会整理一次。想立刻记点什么用 `/记住`。

**冷却还剩多久？**
`/画图状态`、`/语音状态`、`/视频状态` 会显示本群剩余冷却 —— 但这三条要管理员权限。
普通成员直接试就行，被冷却挡住时机器人会告诉你还剩几秒。

**它为什么突然禁言了？**
管理员发 `/禁言状态` 看最近几次判定，里面有完整依据（严重度、类型、原文前 30 字）。
群主和管理员禁不了，所以你要是管理员，看到的只会是警告。

**它听不懂语音。**
语音识别没做 —— 试过的渠道要么欠费要么没有音频模型。群友发语音，它只知道「有人发了条语音」。
要说话请打字。
