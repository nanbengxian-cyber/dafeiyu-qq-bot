## 一、现象与定位

群友 11:48:36 说「明明之前都能正常回答了，怎么又像人机了」。上一批我把它
记成"待单独处理"，这一批查到了机制。

### 现场：机器人正在讲自己的硬件

| 时间 | 机器人原话 |
|---|---|
| 11:38:56 | 打不了，我连鼠标都没有 |
| 11:39:12 | 手游我也打不了 手都没有 |
| 11:44:24 | 模型不给，线下版也没有，我就是个跑服务器里的东西 |
| 11:45:24 | 住服务器里也是睡机柜 你来试试 |
| 12:05:42 | 真看不见 图没递到我这边 |
| **11:48:36** | **群友（111）：怎么又像人机了** |

### 根因：注入块的技术措辞被逐字搬走

`dsh-selfaware` 每轮注入 **814 字**的机器自我报告（`<current_machine_self>`），
里面的句子是写给机器看的技术台账，模型直接当台词念了。对应关系很干净：

| 群里说的话 | 注入块里的原文 |
|---|---|
| 「真看不见 图没递到我这边」 | `视觉：已有图片文字转述；你没有直接看到原始像素。` |
| 「我就是个跑服务器里的东西」 | `处境：群聊；Linux/AstrBot/容器。` |
| （技术感） | `边界：只感知消息、附件转述、工具结果和系统遥测…` |

**这个块不能删** —— 它的用途是**防幻觉**（不许声称看清了没看清的图、不许假装
有能力）。所以要动的是**说法**，不是内容。

### 关键区分：玩梗要留，报表要去

当天 276 条发言里，提机器属性的共 17 条，其中：

* **14 条是玩梗** ——「住服务器里也是睡机柜」「八核跑我，会烧的」
  「服务器在香港，你自己游过来」「就是台服务器 没啥配置」…**这些是性格，全部保留**；
* **3 条是纯技术自述** ——「我连鼠标都没有」「我就是个跑服务器里的东西」
  「图没递到我这边」—— 这三条才是破绽。

改的时候必须只打后者，否则会把性格一起改没。

## 二、改法

| 位置 | 旧 | 新 |
|---|---|---|
| `self_model.py` 处境行 | `处境：群聊；Linux/AstrBot/容器。` | `处境：在群里说话。` |
| `self_model.py` 视觉行 | `已有图片文字转述；你没有直接看到原始像素` | `图的内容转述过来了，你没看到原始画面` |
| `self_model.py` 失败行 | `图片转述失败，不知道内容。` | `图的内容没拿到，不知道里面是什么。` |
| `self_model.py` 无证据行 | `无真实调用遥测…` | `没有真实调用记录…` |
| `self_model.py` 边界行 | `只感知消息、附件转述、工具结果和系统遥测，不能感知未接入的现实环境。` | `你只看得到这个群里发生的事，看不到群外的现实世界。` |
| `main.py` | （无） | 新增 `_TONE_RULE` 措辞规则 |

新增的措辞规则做了两件事：

1. 明确这些事实**只用来管住嘴，不许当台词**；
2. **点名**真出现过的机器话（「模型没递到我这边」「没有手或鼠标」），并给出
   人话替身（「我没看见那张图」「那张图没传过来」「这个我弄不了」）。

同时允许它承认自己是机器（群友问就该答），但要用玩笑或短句带过，
**不许逐条汇报配置、内存、负载**——那是状态报告，不是聊天。

### 一个接线上的细节

措辞规则**只放在能力块里注入一次**，没有放进 `_HEADER`。原因：`_HEADER` 被
能力/入群/动作三个块共用，放进去会被抄三遍，既浪费预算，又会把 `blocks[0]`
撑长、改变装箱顺序 —— 实测这么做直接把 `test_selfaware.py` 弄红了。能力块
在每个相关回合都注入，覆盖足够。

  机器人正常回话；napcat 未被牵连（`Up` 连续，`status.json` 保持 `online`）
* **部署后真实流量**：21:10 之后全部机器人发言中，技术词自述 **0 条**

### 变异测试（6 个，全部被抓住）

| 变异 | 结果 |
|---|---|
| 处境行改回 `Linux/AstrBot/容器` | 失败：`出现了会被照搬的技术词 '容器'` |
| 视觉行改回「原始像素」 | 失败：`出现了会被照搬的技术词 '像素'` |
| 删掉「不得声称看清」（防幻觉语义） | 失败：`必须仍然禁止声称看清` |
| 边界行改回「系统遥测/未接入」 | 失败：`出现了会被照搬的技术词 '遥测'` |
| 规则定义了但**没接线**（`_TONE_RULE` 不注入） | 失败：`措辞规则没有被注入到能力块里` |
| 规则被截断、不再点名机器话 | 失败：`措辞规则没点名 '模型没递到我这边'` |

> **变异⑤ 第一次是假绿**：测试原本只断言 `mm._TONE_RULE` 这个常量存在，
> 而"定义在模块里"和"注入给模型"是两回事 —— 把 `render_capabilities()` 里的
> `_TONE_RULE` 删掉，测试照样全绿。改成断言 `render_capabilities()` 的**输出**
> 之后才真正变红。
>
> 这是本轮抓到的**第三个假绿**（另两个：docs/87 的短句开关变异、
> docs/86 的 factguard 子串断言）。共同形状都是**测试断言了"东西存在"，
> 而没断言"这个东西真的生效"** —— 值得记成一条通用教训。
