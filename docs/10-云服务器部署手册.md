## 一、为什么必须上云

| 你现在的痛点 | 云端方案解决方式 |
|-------------|---------------|
| PC 必须开机 | 云服务器 7×24 在线，PC 彻底关机 |

## 二、服务器选购

### 2.1 推荐配置

| 项目 | 最低配置 | 推荐配置 | 说明 |
|------|---------|---------|------|
| CPU | 1 核 | 1~2 核 | 纯文本对话 1 核足够 |
| 内存 | 1 GB | 2 GB | 跑 Docker + NapCat + AI 服务 |
| 硬盘 | 20 GB SSD | 40 GB SSD | 聊天记录、表情包、日志会增长 |
| 带宽 | 3 Mbps | 5 Mbps | 语音/图片消息需要带宽 |
| 系统 | Debian 12 / Ubuntu 22.04 | Debian 12 | 稳定、Docker 支持好 |

### 2.2 购买渠道

| 厂商 | 产品名 | 月租（新用户） | 链接 |
|------|--------|-------------|------|
| 腾讯云 | 轻量应用服务器 | ~10 元/月 | https://cloud.tencent.com |
| 阿里云 | 轻量应用服务器 | ~10 元/月 | https://www.aliyun.com |
| 华为云 | 云耀云服务器 | ~15 元/月 | https://www.huaweicloud.com |
| 雨云 / 狗云 | 境外轻量 VPS | ~20~30 元/月 | 免备案，适合折腾 |

> **提示**：国内厂商需要实名认证+备案（服务器本身不用备案，但 80/443 端口可能需要）。如果嫌麻烦，直接买境外 VPS（如 Racknerd、Vultr、雨云），免备案，即买即用。

### 2.3 购买后必做

1. **重置 root 密码**（控制台操作）。
2. **放行端口**：在安全组/防火墙里放行以下端口：
   - `22`（SSH）
   - `3001`（NapCat WebUI）
   - `6185`（AstrBot WebUI）
   - `6186`（AstrBot API，可选）
3. **SSH 连接**：
   ```bash
   ssh root@你的服务器IP
   ```

## 三、环境准备：安装 Docker + Docker Compose

以下命令在服务器上逐行执行。

### 3.1 更新系统

```bash
apt update && apt upgrade -y
```

### 3.2 安装 Docker

```bash
# 官方一键安装脚本
curl -fsSL https://get.docker.com | sh

# 验证安装
docker --version
# 应输出类似：Docker version 27.x.x
```

### 3.3 安装 Docker Compose

```bash
# 安装 compose 插件（新版 Docker 已内置）
docker compose version

# 如果提示未找到，手动安装：
apt install -y docker-compose-plugin

# 旧版备用方案
# apt install -y docker-compose
```

### 3.4 设置 Docker 开机自启

```bash
systemctl enable docker
systemctl start docker
```

### 3.5 创建项目目录

```bash
mkdir -p /opt/qqbot && cd /opt/qqbot
mkdir -p napcat/config astrbot/data
```

## 四、部署 NapCat（QQ 协议端）

NapCat 基于官方 NTQQ 客户端，通过 Hook 技术暴露 OneBot 协议接口。它负责：
- 登录你的 QQ 小号
- 接收群聊/私聊消息
- 发送回复消息（文字、图片、语音、表情包）

### 4.1 创建 NapCat 配置文件

```bash
cat > /opt/qqbot/napcat/config/onebot11.json << 'EOF'
{
  "http": {
    "enable": false,
    "host": "0.0.0.0",
    "port": 3000,
    "secret": "",
    "heartbeat_interval": 5000
  },
  "ws": {
    "enable": true,
    "host": "0.0.0.0",
    "port": 3001
  },
  "reverse_ws": {
    "enable": false,
    "url": ""
  },
  "token": "你的自定义Token"
}
EOF
```

> **注意**：把 `你的自定义Token` 换成一个随机字符串（如 `qqbot_2026_xyz789`），后续 AstrBot 连接时需要用到。

### 4.2 启动 NapCat

```bash
docker run -d   --name napcat   --restart=always   -p 3001:3001   -v /opt/qqbot/napcat/config:/app/config   -e NAPCAT_UID=1000   -e NAPCAT_GID=1000   mlikiowa/napcat-docker:latest
```

### 4.3 查看日志并扫码登录

```bash
docker logs -f napcat
```

等待日志输出二维码链接，类似：
```
请访问 http://服务器IP:3001/qrcode 扫码登录
```

在浏览器打开 `http://你的服务器IP:3001`，进入 NapCat WebUI，扫码登录你的 **QQ 小号**。

> ⚠️ **重要**：务必使用小号！不要用主号！

登录成功后，日志会显示：
```
[Core] [Login] 登录成功
```

按 `Ctrl+C` 退出日志查看。

### 4.4 NapCat 常用命令

```bash
# 查看状态
docker ps | grep napcat

# 重启
docker restart napcat

# 查看实时日志
docker logs -f --tail=100 napcat

# 停止
docker stop napcat

# 彻底删除（保留配置）
docker rm napcat
```

## 五、部署 AstrBot（AI 聊天框架）

AstrBot 是开源的 AI 聊天机器人框架，自带 Web 管理面板、多模型支持、插件市场、持久化记忆。

### 5.1 启动 AstrBot

```bash
docker run -d   --name astrbot   --restart=always   -p 6185:6185   -p 6186:6186   -v /opt/qqbot/astrbot/data:/AstrBot/data   soulter/astrbot:latest
```

### 5.2 初始化配置

1. 浏览器访问 `http://你的服务器IP:6185`
2. 首次进入会要求设置管理员密码，设置好记住。
3. 进入「消息平台」→「适配器」→ 添加 **OneBot V11**
   - 连接方式：`正向 WebSocket`
   - 主机：`napcat`（因为都在 Docker 网络里，用容器名即可）
   - 端口：`3001`
   - Token：填你刚才在 `onebot11.json` 里设置的 Token
   - 保存并启用

> 如果 AstrBot 和 NapCat 不在同一台机器，主机填 `你的服务器IP`，端口 `3001`。

### 5.3 配置 AI 模型

进入「提供商」→ 添加你的模型：

| 模型类型 | 配置方式 |
|---------|---------|
| **DeepSeek** | 选「OpenAI 兼容」，Base URL 填 `https://api.deepseek.com/v1`，API Key 填你的 Key |
| **智谱 GLM** | 选「ZhipuAI」，填 API Key |
| **OpenAI** | 选「OpenAI」，填 API Key |
| **本地 Ollama** | 选「Ollama」，Base URL 填 `http://localhost:11434` |

### 5.4 配置人格（Prompt）

进入「对话」→「人格」，编辑系统提示词：

```
你是一个群聊助手，名字叫「小D」。
你说话幽默、略带 sarcastic，喜欢用网络梗。
群友发图片时，你会尝试理解图片内容并评论。
群友发语音时，你会转写内容后回复。
```

保存后，在群里发消息测试。

### 5.5 AstrBot 常用命令

```bash
# 查看日志
docker logs -f --tail=100 astrbot

# 重启
docker restart astrbot

# 进入容器内部调试
docker exec -it astrbot sh

# 停止
docker stop astrbot
```

## 六、整合：Docker Compose 一键编排（推荐）

如果你觉得上面分步太麻烦，直接用下面这份 `docker-compose.yml`，一条命令拉起全部。

### 6.1 创建编排文件

```bash
cat > /opt/qqbot/docker-compose.yml << 'EOF'
version: "3.8"

services:
  napcat:
    image: mlikiowa/napcat-docker:latest
    container_name: napcat
    restart: always
    ports:
      - "3001:3001"
    volumes:
      - ./napcat/config:/app/config
    environment:
      - NAPCAT_UID=1000
      - NAPCAT_GID=1000
    networks:
      - qqbot-net

  astrbot:
    image: soulter/astrbot:latest
    container_name: astrbot
    restart: always
    ports:
      - "6185:6185"
      - "6186:6186"
    volumes:
      - ./astrbot/data:/AstrBot/data
    depends_on:
      - napcat
    networks:
      - qqbot-net

networks:
  qqbot-net:
    driver: bridge
EOF
```

### 6.2 一键启动

```bash
cd /opt/qqbot
docker compose up -d
```

等待 30 秒，然后：
1. 访问 `http://服务器IP:3001` 扫码登录 QQ
2. 访问 `http://服务器IP:6185` 配置 AstrBot
3. 在 AstrBot 的 OneBot 适配器里，主机填 `napcat`（因为 Docker 内部网络互通）

### 6.3 一键停止/重启

```bash
# 停止全部
docker compose down

# 重启全部
docker compose restart

# 查看全部日志
docker compose logs -f

# 只查看 AstrBot 日志
docker compose logs -f astrbot
```

## 七、迁移你现有的 AI 服务

你目前在手机上跑的 AI，大概率是以下几种情况之一：

### 情况 A：调用远程 API（如 DeepSeek、智谱、Claude）

**迁移方式**：直接在 AstrBot 里配置 API Key，零代码迁移。
- 进入 AstrBot WebUI →「提供商」→ 添加对应平台 → 填 Key → 完成。
- 你手机上的代码可以退休了。

### 情况 B：本地运行大模型（如 Termux 跑 llama.cpp）

**迁移方式**：
1. 服务器上安装 Ollama：
   ```bash
   curl -fsSL https://ollama.com/install.sh | sh
   ```
2. 拉取模型：
   ```bash
   ollama pull qwen2.5:7b
   ```
3. AstrBot 里添加 Ollama 提供商，Base URL 填 `http://localhost:11434`。
4. 手机上的模型可以删了。

> 注意：1核1G 服务器跑 7B 模型会很卡，建议至少 2核4G。如果预算不够，还是走远程 API 路线。

### 情况 C：自定义 Python 脚本（自己写的逻辑）

**迁移方式**：
1. 把脚本搬到服务器上，确保能独立运行。
2. 修改脚本，让它暴露一个 HTTP API（如 Flask/FastAPI）：
   ```python
   from flask import Flask, request, jsonify
   app = Flask(__name__)

   @app.route('/chat', methods=['POST'])
   def chat():
       data = request.json
       message = data.get('message')
       # 你的 AI 逻辑
       reply = your_ai_logic(message)
       return jsonify({"reply": reply})

   if __name__ == '__main__':
       app.run(host='0.0.0.0', port=5000)
   ```
3. 用 Docker 跑这个脚本：
   ```bash
   docker run -d --name myai -p 5000:5000 -v /opt/qqbot/myai:/app your-image
   ```
4. 在 AstrBot 里添加「自定义 HTTP 提供商」，指向 `http://localhost:5000`。

## 八、保活与风控规避

### 8.1 容器自动重启

上面所有 `docker run` 和 `docker-compose.yml` 都已配置 `--restart=always`，服务器重启后容器会自动拉起。

### 8.2 服务器重启后自动启动 Docker

```bash
systemctl enable docker
```

### 8.3 QQ 风控规避（关键！）

| 风险行为 | 规避措施 |
|---------|---------|
| 秒回消息 | AstrBot 默认有随机延迟，可在「对话」设置里调整为 1~3 秒 |
| 24h 不间断活跃 | 设置夜间模式：0:00~7:00 降低回复频率或只回复 @消息 |
| 频繁发链接/图片 | 控制多媒体发送频率，避免连续发图 |
| 被举报 | 不要主动骚扰群友，只在被 @或群聊触发时回复 |
| 登录异常 | 服务器买好后固定 IP，不要频繁换地区登录 |

### 8.4 定期备份

```bash
# 备份聊天记录和配置
tar czvf /root/qqbot-backup-$(date +%Y%m%d).tar.gz /opt/qqbot

# 设置定时备份（每周日凌晨 3 点）
crontab -e
# 添加：
0 3 * * 0 tar czvf /root/qqbot-backup-$(date +\%Y\%m\%d).tar.gz /opt/qqbot
```

## 九、进阶：接入你的长期目标

### 9.1 表情包发送

AstrBot 原生支持发送图片。你可以：

**方案一：本地图库**
1. 在服务器上创建目录 `/opt/qqbot/astrbot/data/images/emoji/`
2. 放入表情包图片，命名如 `doge.jpg`、`panda.png`
3. 在 AstrBot 人格 Prompt 里加一句：
   ```
   当你想表达「无语」时，发送图片 [CQ:image,file=/AstrBot/data/images/emoji/doge.jpg]
   ```

**方案二：向量语义匹配（更智能）**
参考开源项目 `QQSafeChat` 的 StickerSelector 思路：
1. 本地部署 `m3e-small` 向量模型（轻量，CPU 可跑）。
2. 表情包库每张图提取语义向量。
3. AI 生成回复时，对回复文本做向量检索，匹配最相关的表情包发送。

### 9.2 语音回复

**链路**：TTS 生成音频 → 转 SILK 格式 → CQ 码发送

```bash
# 安装 edge-tts（免费）
pip install edge-tts

# 生成语音
edge-tts --text "你好啊群友" --write-media output.mp3

# 转 SILK（需 silk-v3-decoder）
# AstrBot/NapCat 部分版本支持直接发 mp3 自动转码
```

在 AstrBot 里开启语音回复功能（部分版本支持，或写插件实现）。

### 9.3 记忆系统

**短期记忆**：AstrBot 自带，自动保留最近 N 条对话上下文。

**长期记忆/群友画像**：
1. 在 AstrBot 插件市场里搜索「记忆」相关插件。
2. 或自行开发插件，接入 SQLite：
   - 表 `users`：user_id, nickname, persona_summary, updated_at
   - 表 `messages`：id, user_id, content, timestamp
   - 每周用 AI 对高频用户的消息做摘要，更新 persona_summary。
   - 回复时把该用户的 persona_summary 注入 System Prompt。

### 9.4 视觉理解

AstrBot 支持图片消息接收。在提供商里配置支持视觉的模型（如智谱 GLM-4V、Qwen-VL），群友发图时 AstrBot 会自动把图片 URL 传给模型分析。

## 十、常见问题排查

### Q1: NapCat 扫码后显示「登录失败」或「版本过低」

**解决**：
```bash
docker pull mlikiowa/napcat-docker:latest
docker compose down
docker compose up -d
```
确保镜像是最新版。QQ 客户端版本更新频繁，NapCat 会跟进。

### Q2: AstrBot 连不上 NapCat，显示「WebSocket 连接失败」

**排查步骤**：
1. 确认 NapCat 已登录成功：`docker logs napcat | grep "登录成功"`
2. 确认端口放行：安全组/防火墙放行 3001
3. 确认 Token 一致：AstrBot 里填的 Token 和 `onebot11.json` 里的一致
4. 如果 AstrBot 用 Docker，主机填 `napcat`；如果 AstrBot 在宿主机跑，主机填 `127.0.0.1`

### Q3: AI 回复很慢或报错

**排查**：
1. 查看 AstrBot 日志：`docker compose logs -f astrbot`
2. 确认 API Key 有效、余额充足
3. 如果用的是境外模型（如 Claude），确认服务器能翻墙（境外 VPS 无此问题）
4. 在 AstrBot 设置里调低 `max_tokens`，减少生成时间

### Q4: QQ 被封了怎么办

**预防**：
- 始终用小号
- 控制频率（AstrBot 可设置冷却时间）
- 定期修改 QQ 密码（有开发者反馈改密码后风控降低）

**补救**：
- 去 QQ 安全中心申诉
- 换一个小号重新扫码登录

### Q5: 服务器重启后 QQ 掉线了

NapCat 的登录状态保存在容器内，重启后可能需要重新扫码。建议：
- 尽量减少服务器重启
- 或配置持久化登录态（部分版本支持）
