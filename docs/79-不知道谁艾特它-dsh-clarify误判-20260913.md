# 79 · 「不知道谁艾特他」根因与修复（dsh-clarify）

2026-09-13 · 主群 476573490

## 一、群主报的现象

> 现在群里还有一个问题他好像不知道谁艾特他，上下文逻辑有点问题

当天 12:34~12:44 的实例（主群，全部来自 astrbot.log）：

| 群友（@ 了它） | 说的 | 它回的 |
| --- | --- | --- |
| 木舟F& | 那我去香港能不能找你？ | 找我？ 我人不在香港啊 |
| 宅鱼🦞 | 这个是谁（连问 3 次） | 不认识，看着像哪个游戏的角色 / 又是蓝毛 怎么一个都不认识 |
| 瓦雷莎 | 那你让我去香港 | 去香港照谁啊 |
| 青狼-无念 | 我又来了 | [At:1247816535] 又来了，你这一天天的 |
| **Roy** | **想你了** | **想谁啊** ← 然后 **叫我干嘛** |
| 汪 | 你的也是 | 谁扣的 我怎么不知道 |

最典型的是 Roy 那两句：明知对方 @ 了它说「想你了」，它回「想谁啊」，被补了一句「你」之后又回「叫我干嘛」——看起来就像不知道谁在跟它说话。

## 二、根因：dsh-clarify 的语境分类器看不到「这条是点名」

翻当时完整管道日志，元凶是 `dsh-clarify`（2026-09-12 部署的「含糊新话题先问清楚」插件）：

```
[dsh-clarify.main:308]: [clarify] 注入自然追问 被点名 missing=想谁 q=想谁了？
[dsh-clarify.main:308]: [clarify] 注入自然追问 被点名 missing=妈妈指谁 q=妈妈是谁？
[dsh-clarify.main:308]: [clarify] 注入自然追问 被点名 missing=踩背对象不明 q=给谁踩踩背？
[dsh-clarify.main:308]: [clarify] 注入自然追问 被点名 missing=缺指代对象 q=你是在跟谁说爱你？
```

两条缺陷叠加：

1. **分类器拿不到点名事实。** `_recent(gid, current)` 拼 transcript 时把最后一条写成
   `（刚刚这条）想你了`，和普通群聊消息长得一模一样。`addressed`（`is_at_or_wake_command`）
   只用在了 `decide_action` 分岔上，**从未传给分类器**。模型眼里「想你了」就是一句没主语的
   短句，按 prompt 第 4 条（缺主语/对象即 unclear）必然判 unclear。

2. **unclear + 被点名 = 强制注入追问。** `decide_action` 返回 `ask`，`render(question)` 把
   `<clarification>` 塞进 prompt，里面明写「这次只自然地追问一句，意思按『想谁了？』」。
   主模型于是照着写「想谁啊」——**不是它不知道谁在跟它说话，是被插件按着头去追问**。

当天这类「被点名仍追问」共出现 40+ 次（含 00:32 指什么、09:38 谁不准、12:28 想谁、
12:34 找谁、12:36 香港找、12:42 指代对象不明）。这是个**长期高频**的偏差，只是这次被群主
抓到了最明显的两连击。

## 三、修复（dsh-clarify 镜像）

三处改动，全部在镜像 `plugins/dsh-clarify/main.py`：

1. **把点名事实喂给分类器**：`_recent()` 新增 `addressed` 参数，最后一条改成
   `（这条是 @ 机器人 才说的）想你了`；调用点改为 `_recent(gid, text, addressed)`。
2. **prompt 加规则 7**：最后一句若是特意 @ 机器人，指代对象就是机器人本人；被点名时
   短句/玩梗/感叹/寒暄（想你了、你的也是、顶你、又来啦）直接判 `connected`。
3. **代码哨兵 `short_and_addressed()`**：只加 prompt 管不住模型（实测「爱你」依旧被追问成
   「你是在跟谁说爱你？」），所以再加一道确定性闸门——被点名、`≤4` 字、且不含
   `这/那/啥/谁/哪/怎么/怎/为什么/干啥/干嘛/什么` 的句子，直接 `clear` 放行，不进分类器。

部署：备份 `main.py.bak-20260913-055745`（第一版）与 `main.py.bak.short-20260913-061234`，
只重启 AstrBot，未动 NapCat / QQ 出口 / 代理 / 多模态配置。上线确认：

```
[clarify] 已加载：开 群=476573490 回看6条/300s 超时12s 冷却300s
```

回归测试（容器内 py3.12）：`CLARIFY_TEST_OK`，新增断言覆盖「爱你/想你了/踩踩背/顶你/戳你
放行」「这啥/谁/干嘛/弄疼谁 仍交分类器」「长句不受影响」。

## 四、副作用与边界

- 短句哨兵只在**被点名**时生效（未点名的短句仍走原有的 unclear→沉默/不抢话逻辑）；
- 阈值 4 字是保守取值：「弄疼谁」「这是哪里」这类带指代词的照旧交给分类器；
- 被点名且真缺信息时（如「妈妈是谁」这种需要确认的）仍保留追问能力。
