# QQ 机器人整体瘦身审计（保留精华）

> 范围：源码镜像审计与最小改造；不直接部署生产。当前源码基线按 53 个 `dsh-*` 插件目录计算（后台审计启动时为 52 个，期间已有 `dsh-agency` 落入工作树）。

## 结论

问题不在“插件数量本身”，而在多个插件同时向每轮 LLM 请求追加独立上下文，且个别预算只统计正文、不统计固定说明。生产日志实证：单轮通常清理 12～14 个旧注入块；`selfaware` 常注入约 1066～1100 字，`memory` 配置预算 520 字但实际日志达到约 606～800 字，另有 `scene` 约 187～199 字、`style` 约 267～283 字，以及按需的 social/slang/desire/glossary。继续删插件会损失能力，先把预算变成真实硬上限、把诊断信息改成按需出现，收益更高且风险更低。

本轮不合并或删除插件。保留选择性参与、语境澄清、人格口吻、记忆、社交边界、自我感知、安全闸、多模态和群黑话；只削减每轮重复的提示词负载。

## 已实施的最小改造

### 1. 记忆块预算修正

`dsh-memory` 的 `DSH_MEM_INJECT_BUDGET` 现在覆盖完整 `<member_memory>`：固定安全说明、正文、换行和标签都计入。以前 520 只限制正文，固定说明额外叠加，所以线上可出现约 800 字；现在完整块不会超过配置预算，预算不足时宁可少带低权重条目或不注入，也不会截断 XML 标签。

保留内容与顺序不变：当前说话者资料优先，其次在场群友和群共同记忆；“没有资料就不要编”的防幻觉语义仍保留。

### 2. 自我感知分层

`dsh-selfaware` 默认总预算由 1900 收紧到 1400，当前机器事实改为更短的等价表达。保留：封闭能力清单、真实遥测、视觉边界、运行资源、近期真实动作和入群审核。

近 30 天长期可靠性从“每轮固定注入”改为“异常或被明确询问自身能力/状态时注入”。长期数据和 `/自我感受` 命令没有删除，只是不再在普通闲聊里反复占用上下文。短期异常仍会立即带入，不会为了省字掩盖故障。

### 3. 修复一段名存实亡的输出链路

`dsh-noise` 原先命中换字/截断/叠词后会生成新消息链并增加统计，但 `changed` 从未置为真，导致新链永远不写回、日志看似执行实际正文不变。现在命中真实变化时置位并写回；新增集成回归锁住该行为。这个修复不扩大适用范围，被 @ 的正经回答仍然跳过噪点。

## 明确保留的精华

- **人格与人味**：真人短句样本、出口去 AI 味、错别字/噪点链路不删。
- **判断与参与**：decide、clarify、followup、initiate/proactive/desire 保持现状；本轮不引入随机叛逆。
- **记忆与关系**：成员记忆、群记忆、社交距离、黑话理解均保留，只限制实际注入尺寸。
- **自我与边界**：能力清单、真实动作、机器遥测、感知边界和长期统计均保留。
- **安全**：armor、guard、claim/fact/leak/selfworth/selfguard、联网出口审核等不动。
- **多模态**：图片、视觉链、视频、语音、网页和转发解析均不动；不改任何 provider 配置。

## 暂不实施的高风险合并

1. `dsh-aiflavour` 与 `dsh-humanizer` 静态强/弱词表明显重叠，生产日志中同一句软信号会被两者各记录一次。但前者还承担动态学习和会话刹车，直接合并会迁移持久化状态和命令接口；当前收益主要是少一次字符串扫描，不值得本轮冒行为漂移风险。
2. 主动参与相关插件职责相邻，但分别承担兴趣、续聊、发起和动机状态。没有统一编排器和离线回放前，不应靠删除开关“瘦身”。
3. 不把所有上下文插件立即物理合成一个巨型插件。那会降低模块隔离性并扩大故障半径；下一步应先做共享预算/观测层，再决定是否合并实现。
4. `dsh-video` 自动理解目前受 AstrBot 适配器不产出 `[Video Attachment]` 标记限制；`dsh-merge` 的后台 `send_message` 也绕过常规结果装饰链。这两项涉及框架适配或出口架构，不能混进本轮低风险瘦身，必须单独设计、回放和验证。
5. `armor`、`merge`、`decide` 同为 priority=2000，等优先级顺序依赖框架注册顺序。应在下一轮明确拆成不同优先级，而不是本轮未经全链回放直接改动准入行为。

## 验证与观测

回归测试覆盖：记忆完整块硬预算、自我遥测解析/状态时效/长期统计、自我感知预算与 XML 完整性、集成注入和响应遥测。建议部署后只观察一轮自然流量，再比较日志中的：

- `[memory] ... / N 字`：应不再超过 `DSH_MEM_INJECT_BUDGET`。
- `[selfaware] ... 长期=0/1 ... N字`：普通闲聊应为 `长期=0`，问能力或出现异常时可为 `1`，总字数不超过预算。
- 回复长度、答非所问率、记忆命中和澄清行为：不应出现明显回退。

## 部署边界与回滚

本轮没有修改生产。若决定部署，只需同步 `dsh-memory/main.py` 与 `dsh-selfaware/{main.py,self_model.py,metadata.yaml}`，保留 root:root / 600，并只重启 AstrBot；无需且不得改动 NapCat、QQ 出口、代理、路由和多模态 provider。建议先备份这两个插件目录与环境文件；无需新增环境变量，旧配置仍兼容。回滚时还原上述文件并重启 AstrBot即可。
