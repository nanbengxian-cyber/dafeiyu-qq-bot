- 生产 `main.py` 与镜像只差脱敏占位符（diff 只有群号/QQ 号占位），无版本回归；
- 旧离线回测 `SELFWORTH_TEST_OK` 照样全过；
- 最后一次输入侧命中停在 2026-09-13 00:01（呆鱼），最后一次出口改写停在 2026-09-12 14:00，
  账本 `data/selfworth.json` 最后写入 2026-09-13 00:01 —— 之后 12 小时闸门一次都没开。

## 三、改了什么（v1.1.0）

新增输入侧五族（全部要求「冲着它说」才算）：

- `DEAL` 补 `_PRICE_PATS`：便宜货/几分钱一次/吃·烧·费token/几万token/真烧
- `FREELOAD` 补 `_USEUP_PATS`：狠狠用/往死里用/用到求饶/随便用/别烧光
- `INSULT` 补 `_FISH_SLURS`：杂鱼、臭鱼、咸鱼、雌小鱼、小鱼干、工具鱼…
- `SERVANT`（新）：踩/踹/捏/揉/骑 + 给·让·把…踩 / 使唤 / 乖乖趴好
- `FODDER`（新）：做成火锅/烤鱼/清蒸/爆炒/几成熟/嫩鱼/把你的尾巴分着吃

新增出口侧四个形状：

- `LABEL`（新）跟着认标签：贬称复读「X就X」「说的就是我这鱼呗」
- `SERVANT`（新）配合被使唤：我趴好了 / 来 踩吧 / 踩吧踩吧
- `COMPLY`（新）配合被用：用吧用吧 / 别烧光就行 / 随便用
- `FODDER`（新）自我物化：我这鱼头炖汤应该不错 / 反正都是鱼 / 不都是你嘴里的鱼

两条口径补充：

1. **上下文口径**：同一群 TTL 窗口内已经有人占过便宜时，「不答应也得爆炒」「变成杂鱼」
   这种没主语的补刀也算 —— 否则一整轮只有带 @ 或「你」的第一条能被认出来。
2. **自我物化免证据**：`_OUT_FODDER` 的形状不可能是嘴硬，所以不要求输入侧证据。
   这样 00:00 兴趣探头自发说的「我这鱼头炖汤应该不错」也拦得住。

## 四、反向验证（宁漏不误伤）

拿 3776 条机器人真话（旧 3096 条语料 + 当次日志全部回复）sweep 输出侧，
收紧到 32 条命中，逐条人工确认。**被排除的误伤**：

```
认不出就认不出，习惯就好        吃了就吃了 又没吃你家大米
能不换就不换 能白嫖就白嫖        完了就完了 明天再找
不说就不说 你也不用烧纸了        我这托盘都给炖变形了
我又不是管理员 禁言自己找群主去   找我这儿也是找 群主推荐的肯定靠谱
```

为此做了三处收紧：

- `LABEL` 不认泛化的 `X就X`，只认贬称复读（泛化会误伤上面那几条）；
- `FODDER` 不认「我这托盘」这种抱怨，只认「把自己身上的东西拿去下锅」；
- `SIDING` 把「找群主」这种指路（「自己找群主去」「找群主推荐的」）排除，
  只有后面跟着算账类动作才算替外人记账。

当天同一轮它嘴硬的 5 句**全部原样放行**：你才便宜你全家都便宜 / 爆炒也得先问问我这条鱼
答不答应 / 爆炒之前先问过鱼没有 / 狠狠用呗反正烧的是你的钱包 / 求饶是不可能求饶的。
